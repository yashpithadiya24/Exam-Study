1. Regression શું છે?

Regression supervised learningની રીત છે જેમાં target/output સામાન્ય રીતે numeric value હોય છે. Model independent variables (features) અને dependent variable (target) વચ્ચેનો સંબંધ શીખે છે.

Features X
→
Regression model
→
Numeric prediction Ŷ

Example: House size પરથી price predict કરવી; advertising budget પરથી salesનો અંદાજ કરવો; carના volume અને weight પરથી CO₂ emission predict કરવું.

Trick: Regression → Result number; Classification → Class/category.

2. Simple Linear Regression

એક independent variable Xથી dependent variable Y predict કરે છે. Best-fit straight line શોધાય છે.

Ŷ = b₀ + b₁X
  • Ŷ: predicted Y.
  • b₀ (intercept): X = 0 હોય ત્યારે lineનું predicted Y.
  • b₁ (slope): X એક unit વધે ત્યારે Yમાં થતો અંદાજિત ફેરફાર.

Dots observed data છે; blue line modelનું prediction છે. વાસ્તવિક data line પર જ હોવો જરૂરી નથી.

સરળ solved example

Model: Ŷ = 7 + 20X, જ્યાં X = advertising budget (હજાર unitsમાં) અને Ŷ = sales units.

જો X = 3 હોય, તો Ŷ = 7 + 20(3) = 67 units

Budgetમાં 1 unit વધારો થાય તો model મુજબ sales સરેરાશ 20 units વધે છે.

Interactive prediction

Ŷ = 7 + 20 × 3 = 67.00

3. Ordinary Least Squares (OLS), residual અને RSS

Actual value અને predicted value વચ્ચેનો તફાવત residual/error કહેવાય છે. OLS એવી line પસંદ કરે છે જે squared residualsનો કુલ સરવાળો ઓછો કરે.

Residual: eᵢ = yᵢ − ŷᵢ
RSS = Σ(yᵢ − ŷᵢ)²

Square કરવાથી positive અને negative errors એકબીજાને cancel કરતા નથી અને મોટા errorsને વધુ penalty મળે છે.

નાના RSSનો અર્થ આ dataset પર predictions નજીક છે; પરંતુ માત્ર training RSS નાનું હોય એટલે unseen data પર model સારું જ હશે એવું નથી — overfitting શક્ય છે.

OLS coefficients (simple linear regression)

b₁ = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / Σ[(xᵢ−x̄)²]
b₀ = ȳ − b₁x̄

અહીં x̄ અને ȳ એ X તથા Yના mean છે. પહેલાં slope કાઢો, પછી intercept.

Trick: Residual = actual − predicted; RSS = residualના squaresનો sum.

4. Gradient Descent

Loss function ઓછું કરવા parametersને વારંવાર થોડું adjust કરતો optimization algorithm. Linear/logistic regression અને neural networksમાં ઉપયોગી છે.

Initial weights
→
Loss / Gradient ગણો
→
Negative gradient તરફ step
→
Repeat until convergence
w(new) = w(old) − α × ∂Loss/∂w
  • α (learning rate): દરેક step કેટલો મોટો હોય તે.
  • α ખૂબ મોટો → minimumને ઓળંગી શકે, training unstable થઈ શકે.
  • α ખૂબ નાનો → learning ધીમું થાય.
  • Gradient બતાવે છે loss કઈ દિશામાં અને કેટલો ઝડપથી બદલાય છે; તેથી તેના opposite directionમાં ચાલીએ છીએ.

PDFમાં આપેલા પ્રકારનું solved example

f(x)=x², x₀=1.1, α=0.1 અને f′(x)=2x.

x₁ = x₀ − αf′(x₀) = 1.1 − 0.1(2.2) = 0.88
x₂ = 0.88 − 0.1(1.76) = 0.704
f(x): 1.21 → 0.7744 → 0.4956

દરેક iterationમાં x અને loss 0 તરફ જાય છે. એટલે algorithm minimum તરફ આગળ વધી રહ્યો છે.

Trick: Calculate loss → find slope → go downhill → repeat.

5. Linear Regressionની properties અને assumptions

Properties

  • OLS line squared errorsનો sum minimize કરે છે.
  • Simple OLS regression line dataના mean point (x̄, ȳ)માંથી પસાર થાય છે.
  • b₀ = intercept અને b₁ = slope.

Assumptions — “L-H-N-I-M-O” યાદ રાખો

Assumptionઅર્થઉલ્લંઘનનું ઉદાહરણ
LinearityX અને expected Y વચ્ચે linear relationshipવાસ્તવિક સંબંધ વક્ર હોય
HomoscedasticityResidual variance લગભગ constantમોટા X પર errors વધારે ફેલાય
Normality of residualsResidualsનું distribution લગભગ normalResiduals ખૂબ skewed
IndependenceObservations/errors પરસ્પર independentTime-seriesમાં autocorrelation
No perfect multicollinearityMultiple regressionના predictors એકબીજાની exact linear copy ન હોયX₂ = 2X₁
Outlier checkઅતિ અલગ valuesને તપાસવીએક અસામાન્ય house price line ખેંચી લે

Normality ખાસ કરીને classical inference (tests/confidence intervals) માટે ઉપયોગી assumption છે; દરેક prediction taskમાં બધા assumptionsનું મહત્વ એકસરખું નથી.

6. R-squared (R²)

R² model targetમાં રહેલા variationનો કેટલો ભાગ explain કરે છે તે બતાવતો goodness-of-fit measure છે.

SSres = Σ(yᵢ − ŷᵢ)²
SStotal = Σ(yᵢ − ȳ)²
R² = 1 − SSres / SStotal

Example: SStotal = 100 અને SSres = 30 હોય:

R² = 1 − 30/100 = 0.70

એટલે datasetમાં Yના variationનો 70% ભાગ model દ્વારા explain થાય છે. R² ઊંચું હોવું હંમેશા model યોગ્ય છે તેની ખાતરી નથી; leakage, overfitting અથવા ખોટો model પણ ઊંચું R² આપી શકે.

Trick: R² = 1 − unexplained / total variation. 1ની નજીક સામાન્ય રીતે better fit, પણ test performance પણ તપાસો.

7. Multiple Linear Regression

એક target Y માટે અનેક independent variablesનો ઉપયોગ થાય છે.

Ŷ = b₀ + b₁X₁ + b₂X₂ + … + bₙXₙ

Example: Carનું CO₂ emission predict કરવા engine volume (X₁) અને weight (X₂) વાપરીએ. દરેક coefficient બીજા features સ્થિર રાખીને તે featureનો estimated effect દર્શાવે છે.

Volume X₁
Weight X₂
Age X₃

Exam point: Simple regressionમાં એક predictor; multiple regressionમાં બે કે વધુ predictors. Perfect multicollinearityથી coefficients અલગ પાડવા મુશ્કેલ બને છે.

8. Polynomial Regression

જ્યારે X અને Y વચ્ચેનો સંબંધ straight line કરતાં વક્ર હોય, ત્યારે Xના powers ઉમેરવામાં આવે છે.

Ŷ = b₀ + b₁X + b₂X² + … + bₙXⁿ

Example: Carની ઉંમર વધે તેમ price શરૂઆતમાં ધીમે અને પછી ઝડપથી ઘટે; quadratic term X² curve પકડવામાં મદદ કરી શકે.

Degree બહુ ઊંચી રાખવાથી training dataમાં વધારે વળાંકો fit થઈ overfitting થઈ શકે. Degree validation dataથી પસંદ કરવી.

Trick: Linear = straight line; Polynomial = X², X³…થી curve.

9. Support Vector Regression (SVR)

SVR, Support Vector Machineના વિચારને numeric prediction માટે વાપરે છે. તે એવા functionને શોધે છે જેમાં મોટાભાગના points prediction lineની આસપાસ ε (epsilon) tolerance tubeમાં આવે.

  • ε-insensitive tube: εની અંદરના errorsને lossમાં સામાન્ય રીતે penalty ન આપવાનો વિચાર.
  • Support vectors: tubeની બહાર અથવા boundary પર આવેલા મહત્વના points, જે fitને અસર કરે છે.
  • C: tube બહારના errorsને કેટલો penalty આપવો તેની setting. C વધારે → training errors પર વધુ ભાર, overfitનો જોખમ વધી શકે.
  • Kernel: nonlinear patternને feature spaceમાં handle કરવામાં મદદ કરે છે.
SVRનો હેતુ: flat function + εથી મોટા deviations માટે penalty
Objective (conceptually): ½‖w‖² + C Σ(ξᵢ + ξᵢ*)

અહીં ξ અને ξ* tubeની બહારના deviations માપે છે. Formulaના symbolsને સમજવું મુખ્ય છે: flatness અને errors વચ્ચે trade-off.

Trick: SVR = numeric output + ε tube + support vectors.

10. Kernel Trick અને Kernel types

Data original input spaceમાં straight boundary/fitથી પકડાતું ન હોય, ત્યારે kernel similarity ગણાવી higher-dimensional feature spaceમાં nonlinear relation handle કરાવે છે. ઘણીવાર features explicit રીતે બનાવવાની જરૂર પડતી નથી.

Kernelસરળ વિચારક્યારે ઉપયોગી?
LinearK(x,z)=x·zસંબંધ લગભગ linear હોય
PolynomialK(x,z)=(γx·z+r)ᵈFeature interactions/curvature
RBF / GaussianK(x,z)=exp(−γ‖x−z‖²)Flexible nonlinear patterns
SigmoidK(x,z)=tanh(γx·z+r)કેટલાક neural-like nonlinear patterns
Trick: Linear = સીધું; Polynomial = powers; RBF = નજીકના pointsની similarity; Sigmoid = tanh.

11. Logistic Regression

નામમાં regression હોવા છતાં, Logistic Regression સામાન્ય રીતે classification માટે probability આપે છે — જેમ કે ખરીદી કરશે કે નહીં (0/1).

z = b₀ + b₁X₁ + … + bₙXₙ
p = σ(z) = 1 / (1 + e⁻ᶻ)

Sigmoid કોઈપણ real numberને 0થી 1ની વચ્ચેની probabilityમાં ફેરવે છે. Threshold 0.5 રાખીએ તો p ≥ 0.5 ને class 1 અને નહીં તો class 0 કહી શકાય; threshold task પ્રમાણે બદલાય છે.

z = −3
p ≈ 0.05
z = 0
p = 0.50
z = 3
p ≈ 0.95

Likelihood / Maximum Likelihood Estimation (MLE): model parameters એવા પસંદ કરવા કે observed labels મળવાની likelihood સૌથી વધારે થાય. Binary outcome માટે likelihood میں ہر exampleની predicted probability અને સાચા labelનો ફાળો જોડાય છે.

L = ∏ pᵢʸⁱ (1 − pᵢ)^(1−yᵢ)

અહીં yᵢ=1 હોય તો pᵢનો ફાળો; yᵢ=0 હોય તો (1−pᵢ)નો ફાળો. Computationમાં log-likelihood વાપરવું સામાન્ય છે.

Linear RegressionLogistic Regression
Numeric value predict કરેProbability/class predict કરે
Output range પર fixed limit નથીSigmoid probability 0–1માં
સામાન્ય fit: least squaresસામાન્ય fit: maximum likelihood / log-loss
Trick: Logistic = Sigmoid + Probability + Classification.

12. Regularization, Ridge અને Lasso

Regularization loss functionમાં penalty ઉમેરે છે જેથી weights અતિ મોટા ન બને અને model training data પર જ overfit ન થાય.

Base idea: Total loss = Data-fit loss + λ × Penalty(weights)
MethodPenaltyEffectયાદ રાખવું
Ridge (L2)λΣwⱼ²Weights નાના કરે; સામાન્ય રીતે exact zero નહીંSquare
Lasso (L1)λΣ|wⱼ|કેટલાક weights exact zero કરી શકે; feature selectionમાં મદદAbsolute

λ (lambda): penaltyનું strength. λ = 0 હોય તો penalty નથી; λ બહુ મોટું હોય તો model વધુ simple થઈ શકે અને underfit થાય.

Trick: Ridge = squared weights; Lasso = absolute weights, zero બનાવી શકે.
