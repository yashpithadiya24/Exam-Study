1. Divide and Conquer (D&C)

મોટી problemને નાના subproblemsમાં Divide કરો, subproblems solve કરો (Conquer) અને results જોડો (Combine). Recursionમાં base case જરૂરી છે.

Divide

Input/problemને નાના ભાગમાં તોડો.

Conquer

નાના ભાગોને recursively solve કરો; સરળ base case પર રોકો.

Combine

નાના results જોડીને final answer બનાવો.

T(n) = aT(n/b) + f(n)

અહીં a = subproblemsની સંખ્યા, n/b = દરેક subproblemનું size, f(n) = divide + combineનો ખર્ચ.

2. Recurrence solve કરવી — Master Theorem helper

Standard form: T(n)=aT(n/b)+f(n). પહેલા compare કરો f(n) ને n^(log_b a) સાથે.

Master Theorem 3 cases

CompareResultExample
f(n) polynomial રીતે નાનુંΘ(n^(log_b a))T(n)=2T(n/2)+1 → Θ(n)

Master theorem ફક્ત તેની standard recurrence form અને જરૂરી conditions પૂરી થાય ત્યારે જ વાપરો. અન્ય recurrence માટે substitution અથવા recursion-tree method વાપરી શકાય.

3. Recursion Tree — animated cost by level

Example: T(n)=2T(n/2)+n (Merge Sort). દરેક levelનો કુલ work n જેટલો, levels log₂n + 1 જેટલા.

Tree શરૂ કરવા Next Level દબાવો.

  1. Recursion tree દોરો.
  2. દરેક levelનો cost ઉમેરો.
  3. કુલ levels શોધો: n/2^k = 1 → k = log₂n.
  4. બધા levelsનો cost ઉમેરો.
n levels? નહીં — અહીં log₂n + 1 levels; total Θ(n log n)

4. Binary Search — interactive

Array sorted હોવો જરૂરી. Midpoint જુઓ; target નાનો હોય તો left half, મોટો હોય તો right half રાખો. દર stepમાં search range લગભગ અડધી થાય છે.

Calculation example

Array = [1,3,7,9,11,32,52,74,90], target = 32 (1-based positions as shown in lecture).

  1. low=1, high=9 → mid=⌊(1+9)/2⌋=5 → A[5]=11. 32>11, તેથી low=6.
  2. low=6, high=9 → mid=⌊15/2⌋=7 → A[7]=52. 32<52, તેથી high=6.
  3. low=6, high=6 → mid=6 → A[6]=32. Found at position 6.
T(n)=T(n/2)+Θ(1) → Θ(log n)

દરેક stepમાં low/highને midની યોગ્ય બાજુ update કરો. Sorted ન હોય તો Binary Search લાગુ પડતું નથી.

5. Merge Sort — split અને merge animation

એક-element lists સુધી divide કરો; પછી બે sorted listsને નાની value પહેલાં લઈ merge કરો.

Example: [8, 3, 2, 9, 7, 1, 5, 4]

  1. Split: [8,3,2,9] અને [7,1,5,4].
  2. Further split ત્યાં સુધી કે દરેક subarrayમાં એક element.
  3. Merge pairs: [3,8], [2,9], [1,7], [4,5].
  4. Merge next level: [2,3,8,9], [1,4,5,7].
  5. Final merge: [1,2,3,4,5,7,8,9].
T(n)=2T(n/2)+Θ(n) → Θ(n log n)

Extra memory: સામાન્ય array implementationમાં Θ(n). Merge વખતે બંને sorted halvesમાંથી current smallest element પસંદ કરો.

6. Quick Sort — partition animation

આ notesમાં આપેલી lecture convention મુજબ પ્રથમ element pivot છે. Pivotથી નાના elements left અને મોટા elements rightમાં જાય; પછી બંને sides recursively sort થાય.

Manual example

Array [42,23,74,11,65,58,94,36,99,87], pivot=42.

  1. Leftથી pivot કરતાં મોટો 74 શોધો; rightથી pivot કરતાં નાનો 36 શોધો; બંને swap → 42,23,36,11,65,58,94,74,99,87.
  2. આગળ leftથી 65 અને rightથી 11/પહેલાંની boundary મુજબ pointers cross થાય ત્યારે stop.
  3. Pivotને final partition position પર મૂકો; lectureના exampleમાં 42 પોતાનું position મેળવે છે.
  4. Left અને right subarrays પર ફરી Quick Sort કરો.

Best / Average

Partitions લગભગ સમાન → Θ(n log n).

Worst

Pivot હંમેશાં smallest/largest બને → Θ(n²).

Partition implementation પ્રમાણે intermediate swaps બદલાઈ શકે; pivot partitionની મુખ્ય શરત જાળવવી જરૂરી છે.

7. Large integer multiplication & Strassen

Divide-and-conquer multiplication

બે n-digit numbersને halvesમાં વહેંચો. જો X=a·10ᵐ+b અને Y=c·10ᵐ+d, તો:

XY = ac·10²ᵐ + (ad+bc)·10ᵐ + bd

Example 12×34: a=1,b=2,c=3,d=4,m=1 → ac=3, ad=4, bc=6, bd=8 → 3×100 + (4+6)×10 + 8 = 408.

Strassen matrix multiplication

2×2 matricesને A=[[a,b],[c,d]], B=[[e,f],[g,h]] માનો. સામાન્ય multiplicationમાં 8 scalar multiplications થાય; Strassen 7 products (P₁…P₇) અને additions/subtractionsથી પરિણામ મેળવે છે.

Standard Strassen 7 products

  1. P₁ = (a+d)(e+h)
  2. P₂ = (c+d)e
  3. P₃ = a(f−h)
  4. P₄ = d(g−e)
  5. P₅ = (a+b)h
  6. P₆ = (c−a)(e+f)
  7. P₇ = (b−d)(g+h)

Result C = A×B:

C₁₁=P₁+P₄−P₅+P₇
C₁₂=P₃+P₅
C₂₁=P₂+P₄
C₂₂=P₁−P₂+P₃+P₆

Worked calculation: A=[[1,2],[3,4]], B=[[5,6],[7,8]]

  1. P₁=(1+4)(5+8)=5×13=65
  2. P₂=(3+4)×5=35; P₃=1×(6−8)=−2
  3. P₄=4×(7−5)=8; P₅=(1+2)×8=24
  4. P₆=(3−1)×(5+6)=2×11=22; P₇=(2−4)×(7+8)=−2×15=−30
  5. C₁₁=65+8−24−30=19; C₁₂=−2+24=22
  6. C₂₁=35+8=43; C₂₂=65−35−2+22=50

અંતિમ matrix: [[19,22],[43,50]]. આ standard Strassen formula set teaching example તરીકે ઉમેર્યું છે; source PDFમાં formula diagram સ્વરૂપે છે.

Sign trick: P₁…P₇ પહેલાં અલગથી લખો; પછી C₁₁, C₁₂, C₂₁, C₂₂ formulasમાં values substitute કરો. ખાસ કરીને negative productsના signs ચકાસો.

8. Recurrence numerical — step-by-step

Example A: T(n)=2T(n/2)+n

  1. a=2, b=2, f(n)=n.
  2. n^(log₂2)=n¹=n.
  3. f(n) અને n^(log_ba) same order છે.
  4. Master theorem Case 2 → Θ(n log n).

Example B: T(n)=T(n/2)+1

  1. a=1,b=2,f(n)=1.
  2. n^(log₂1)=n⁰=1.
  3. Same order → Θ(log n).

Example C: T(n)=2T(n/2)+n²

  1. a=2,b=2 → n^(log₂2)=n.
  2. f(n)=n², જે n કરતાં polynomial રીતે મોટું છે.
  3. Regularity condition પૂરી થાય ત્યારે Case 3 → Θ(n²).

9. Quick revision + MCQs

  • Recurrence relation recursive algorithmની running time બતાવે છે.
  • Binary Search: sorted data, Θ(log n).
  • Merge Sort: divide, sort halves, merge; Θ(n log n).
  • Quick Sort: pivot partition; average Θ(n log n), worst Θ(n²).
  • Master theorem parameters: a, b, f(n).
  • Recursion treeમાં દરેક levelનો cost અને levelsની સંખ્યા ઉમેરો.
MCQ 1: Binary Searchમાં input size દરેક stepમાં શું થાય?જવાબ: લગભગ અડધું.
MCQ 2: Merge Sort recurrence કઈ?જવાબ: T(n)=2T(n/2)+Θ(n).
MCQ 3: Quick Sort worst case ક્યારે?જવાબ: સતત અત્યંત અસમાન partitions, ઉદાહરણ તરીકે pivot વારંવાર minimum/maximum બને.
MCQ 4: T(n)=2T(n/2)+nનું order?જવાબ: Θ(n log n).
