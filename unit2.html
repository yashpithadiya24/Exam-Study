2. Entity, DbContext અને DbSet

using Microsoft.EntityFrameworkCore;

public class Product
{
    public int Id { get; set; }       // Primary key convention
    public string Name { get; set; } = "";
    public decimal Price { get; set; }
}

public class AppDbContext : DbContext
{
    public AppDbContext(DbContextOptions<AppDbContext> options)
        : base(options) { }

    public DbSet<Product> Products => Set<Product>();
}
  • Product entity: database rowનું C# representation.
  • DbContext: database session, entity tracking અને save changesનું મુખ્ય object.
  • DbSet<Product>: Products table/query પર કામ કરવાનો interface.
  • SaveChangesAsync(): tracked changes databaseમાં commit કરે.

3. EF Core CRUD — asynchronous code

[ApiController]
[Route("api/[controller]")]
public class ProductsController : ControllerBase
{
    private readonly AppDbContext _db;
    public ProductsController(AppDbContext db) => _db = db;

    [HttpGet]
    public async Task<ActionResult<List<Product>>> GetAll()
        => await _db.Products.AsNoTracking().ToListAsync();

    [HttpGet("{id:int}")]
    public async Task<ActionResult<Product>> Get(int id)
    {
        var p = await _db.Products.FindAsync(id);
        return p is null ? NotFound() : Ok(p);
    }

    [HttpPost]
    public async Task<ActionResult<Product>> Create(Product p)
    {
        _db.Products.Add(p);
        await _db.SaveChangesAsync();
        return CreatedAtAction(nameof(Get), new { id = p.Id }, p);
    }

    [HttpPut("{id:int}")]
    public async Task<IActionResult> Update(int id, Product input)
    {
        var p = await _db.Products.FindAsync(id);
        if (p is null) return NotFound();
        p.Name = input.Name; p.Price = input.Price;
        await _db.SaveChangesAsync();
        return NoContent();
    }

    [HttpDelete("{id:int}")]
    public async Task<IActionResult> Delete(int id)
    {
        var p = await _db.Products.FindAsync(id);
        if (p is null) return NotFound();
        _db.Products.Remove(p);
        await _db.SaveChangesAsync();
        return NoContent();
    }
}
Add
Add(entity) tracked state Added કરે.
Read
ToListAsync(), FindAsync(id) data fetch કરે.
Update
tracked entityની property બદલો, પછી save.
Delete
Remove(entity), પછી save.
CRUD memory: Add → Save → Read; Update/Deleteમાં પહેલાં record શોધો → ફેરફાર કરો → Save. EF Coreમાં SaveChangesAsync() વગર changes સામાન્ય રીતે databaseમાં commit થતા નથી.

5. Change Tracking vs AsNoTracking

Tracking queryNo-tracking query
EF Core entityની state track કરે; property change પછી SaveChangesથી update થઈ શકે.Read-only result માટે tracking overhead ઘટાડે.
ઉદાહરણ: FindAsync, સામાન્ય LINQ query._db.Products.AsNoTracking().ToListAsync()
Update/delete કરવાના entity માટે અનુકૂળ.List/detail display અને reports માટે અનુકૂળ.
યાદ રાખો: “બદલવું છે?” → Tracking; “માત્ર બતાવવું છે?” → AsNoTracking.

6. Async/Await, Task અને LINQ

async methodમાં asynchronous operation લખાય; await operation પૂરી થાય ત્યાં સુધી methodને suspend કરે, સામાન્ય રીતે threadને blocking કર્યા વિના. Task<T> ભવિષ્યમાં મળનાર T resultનું પ્રતિનિધિત્વ કરે છે.

public async Task<Product?> FindProductAsync(int id)
{
    return await _db.Products
        .FirstOrDefaultAsync(p => p.Id == id);
}

7. DTO અને Dapper

DTO (Data Transfer Object): API બહાર મોકલવા/મેળવવા માટેનું સરળ object. તે internal entityને સીધું expose થતું અટકાવે, જરૂરી fields જ મોકલે અને input/output contract અલગ રાખે.

public class CreateProductDto
{
    public string Name { get; set; } = "";
    public decimal Price { get; set; }
}
// Controllerમાં DTOથી entity બનાવો:
var product = new Product { Name = dto.Name, Price = dto.Price };

Dapper: lightweight Micro-ORM. SQL query developer લખે છે અને Dapper resultને C# objectમાં map કરે છે. EF Core વધુ abstraction/change tracking/migrations આપે; Dapper explicit SQL અને ઓછું ORM overhead આપે.

using Dapper;
using Microsoft.Data.SqlClient;

using var connection = new SqlConnection(connectionString);
var employees = await connection.QueryAsync<Employee>(
    "SELECT Id, Name FROM Employees WHERE Department = @Department",
    new { Department = "IT" });
મેમરી ટ્રિક: EF Core = Entity + LINQ + Tracking + Migrations. Dapper = SQL manually + fast mapping. DTO = Data બહાર મોકલવાનો safe shape.
