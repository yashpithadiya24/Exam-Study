Edge connectivity, vertex connectivity, cut-vertex, bridge, separability.

1. Cut-set અને cut-edge

Connected graph Gમાં cut-set એ edgesનો minimal set છે, જેને કાઢવાથી graph disconnected બને. Minimal એટલે આ setમાંથી કોઈ પણ proper subset કાઢવાથી graph હજી connected રહે.

Cut-edge / bridge: એક જ edge કાઢવાથી graph disconnected થાય. એટલે size 1નો cut-set.

Properties

  • Cut-setનો કોઈ proper subset cut-set નથી.
  • Treeની દરેક edge bridge છે.
  • Cut-set કાઢવાથી connected graph બે componentsમાં વહેંચાય છે (course definition મુજબ minimal cut-set).
  • દરેક cut-setમાં દરેક spanning treeની ઓછામાં ઓછી એક branch આવવી જ જોઈએ.
Trick: Cut-set = “કેટલીક edges કાઢો તો connection cut.” Bridge = “એક જ edgeથી cut.”

Rank calculation

Graph rank માટે r = n − k, જ્યાં n vertices અને k connected components. Connected graphમાં k=1 એટલે r=n−1. Cut-set કાઢ્યા પછી બે components થાય તો r=n−2, એટલે rank 1 ઘટે.

Before: r = n − 1
After cut: r′ = n − 2
So r − r′ = 1

Proof idea: every cut-set intersects every spanning tree

માની લો cut-set S કોઈ spanning tree Tની એક પણ edge સાથે common નથી. તો S કાઢ્યા પછી પણ Tની બધી edges રહે છે. T બધા verticesને જોડે છે, એટલે graph disconnected નહીં થાય. આ contradiction છે. તેથી Sમાં દરેક spanning treeની ઓછામાં ઓછી એક branch હોવી જરૂરી.

2. Fundamental cut-set

પસંદ કરેલા spanning tree Tના સંદર્ભમાં એવો cut-set જે exactly one branch ધરાવે તેને fundamental cut-set કહે છે.

  1. Spanning tree પસંદ કરો.
  2. એક branch b કાઢો. Tree બે ભાગમાં વહેંચાશે.
  3. Original graphની જે edges આ બે ભાગ વચ્ચે જાય છે, તે બધું ભેગું કરો.
  4. આ set branch bનો fundamental cut-set છે.
Number of fundamental cut-sets = number of branches = n − 1

n=8 vertices હોય તો spanning treeમાં 7 branches અને તેથી 7 fundamental cut-sets હશે. Tree બદલવાથી sets બદલાઈ શકે, પરંતુ count 7 જ રહેશે.

Mnemonic: “Branch → Cut-set; Chord → Circuit.” Treeની દરેક branch પોતાનો એક fundamental cut-set આપે છે.
Numerical: connected graphમાં n=10. કોઈપણ spanning treeમાં branches=10−1=9, એટલે fundamental cut-sets=9.

3. Fundamental circuits અને cut-sets વચ્ચે relation

એક chord ઉમેરવાથી બનતા fundamental circuitમાં જે branches આવે છે, તે branchesના fundamental cut-setsમાં આ chord દેખાશે.

  • Chord rule: chord જે fundamental circuitમાં છે, તે circuitની દરેક branchના fundamental cut-setમાં આવે છે; બીજા cut-setsમાં નહીં.
  • Branch rule: branchના fundamental cut-setમાં જે chords છે, તેમના fundamental circuitsમાં આ branch આવે છે; અન્ય circuitsમાં નહીં.
Spanning tree T+Chord ઉમેરો→Fundamental circuit
Spanning tree T−Branch કાઢો→Fundamental cut-set
Remember pair: Chord creates cycle; branch removal creates separation. Relationમાં “જે circuitમાં branch છે, એ branchના cut-setમાં chord આવશે.”

4. Connectivity and separability

Edge connectivity λ(G)

Graph disconnect કરવા માટે દૂર કરવી પડે એવી minimum edgesની સંખ્યા. Minimum cut-setનું size.

λ(G) = minimum number of edges whose removal disconnects G

Vertex connectivity κ(G)

Graph disconnect થાય અથવા trivial graph બને તે માટે દૂર કરવી પડે એવા minimum verticesની સંખ્યા (સામાન્ય રીતે complete graph માટે conventional edge cases અલગ હોય છે).

κ(G) = minimum number of vertices whose removal disconnects G
Termશું remove કરીએ?Meaning
Bridge1 edgeએક edgeથી graph disconnect
Cut-vertex / articulation point1 vertexતે vertex કાઢતાં components વધે
Edge connectivityMinimum edgesλ(G)
Vertex connectivityMinimum verticesκ(G)
Separable graphκ(G)=1એક cut-vertex છે

Example: path a—b—c—d માં b અથવા c cut-vertex છે; દરેક edge bridge છે; λ=1 અને κ=1.

Useful inequalities / known results

  • For a connected graph, κ(G) ≤ λ(G) ≤ δ(G), where δ(G) is minimum degree (usual nontrivial graph convention).
  • Tree with at least 2 vertices: edge connectivity = 1.
  • Complete graph Kₙ: λ(Kₙ)=κ(Kₙ)=n−1.
  • Cycle Cₙ (n≥3): λ(Cₙ)=κ(Cₙ)=2.
  • Cut-vertex અને bridge વચ્ચે one-way implication always true નથી: bridge હોઈ શકે પણ તેના endpoints degree conditions મુજબ cut-vertex ન પણ હોય; cut-vertex હોઈ શકે અને incident bridge ન હોય.
Trick: λ = links/edges; κ = vertices/nodes. Greek λ ને links સાથે યાદ રાખો.

5. Worked examples and exam approach

Example A: Tree with 10 vertices has how many cut-sets?

Tree edges = n−1 = 10−1=9. Treeની દરેક edge bridge એટલે size-1 cut-set. તેથી 9 cut-sets of size 1.

Example B: Determine whether edge set S is a cut-set

  1. Given setની બધી edges remove કરો.
  2. Graph connected રહે તો S cut-set નથી.
  3. Disconnected થાય તો Sના દરેક proper subsetને અલગથી test કરો.
  4. બધા proper subsets connected રાખે તો જ minimal cut-set છે.

Example C: κ=2, λ=3, δ=4 possible?

હા, values inequality κ ≤ λ ≤ δ ને satisfy કરે છે: 2 ≤ 3 ≤ 4. Graph construct કરતી વખતે બે vertices કાઢવાથી disconnect થતું હોય, પણ edge disconnect માટે ઓછામાં ઓછી 3 edges કાઢવી પડે અને minimum degree 4 રાખવો.

Written answer structure: Definition → mark removed edges/vertices → show remaining components → minimality/number → conclusion. Proofમાં “assume opposite → contradiction” લખો.

Unit 2: rapid revision

Must memorize

Cut-set minimal edge set
Bridge = cut-set size 1
Fundamental cut-set count = n−1
λ = minimum edges removed
κ = minimum vertices removed

Common traps

Disconnected after removal alone not enough: set must be minimal. A cut-vertex does not always imply a bridge. Spanning tree changes fundamental sets, not their count.

Practice 1: n=12. Number of fundamental cut-sets?Branches = n−1 = 11, so there are 11 fundamental cut-sets.
Practice 2: For C₆, find λ and κ.Cycle needs two edges removed to disconnect, and two vertices removed to disconnect. λ=2, κ=2.
Practice 3: Why must every cut-set contain a branch from every spanning tree?If it had no edge in common with a spanning tree, that spanning tree would remain after deletion and would keep all vertices connected. Contradiction.
