Domination

Selected vertices cover themselves and neighbors.

Domination number

Smallest dominating set; total domination excludes self-cover.

Matching

Edges selected without sharing endpoints.

Hall’s theorem

Condition for a complete matching in bipartite graphs.

1. Neighborhood અને dominating set

Vertex vનો open neighborhood N(v) = vના direct neighborsનો set. Closed neighborhood N[v] = v પોતે + બધા neighbors.

N[v] = N(v) ∪ {v}

Dominating set S: દરેક vertex v માટે, v પોતે Sમાં હોય અથવા Sમાં તેનો કોઈ neighbor હોય. સરળ રીતે: દરેક vertex પર router હોય અથવા એની બાજુના vertex પર router હોય.

Find a dominating set: easy method

  1. High-degree verticesથી શરૂઆત કરો, કારણ કે તેઓ વધુ vertices cover કરે.
  2. દરેક પસંદ કરેલા vertexને પોતે + neighbors તરીકે count કરો.
  3. કોઈ vertex uncovered ન રહે તે check કરો.
  4. Question “any dominating set” કહે તો કોઈ valid set પૂરતો; “minimum” કહે તો સૌથી નાનો set શોધવો.

Complete graph Kₙ: કોઈપણ એક vertex બધા બીજા vertices સાથે adjacent છે, તેથી γ(Kₙ)=1.

Domination number γ(G) = minimum |S| among all dominating sets S
Trick: Dominating = “હું અથવા મારો neighbor.” Selected vertex પોતાને પણ cover કરે છે.

Useful bound from slides

Order n અને maximum degree Δ હોય તો એક vertex વધુમાં વધુ Δ+1 vertices dominate કરી શકે. તેથી:

γ(G) ≥ ⌈ n / (Δ + 1) ⌉

ઉદાહરણ: n=11, Δ=3. એક vertex વધુમાં વધુ 4 vertices cover કરે. 2 vertices વધુમાં વધુ 8, એટલે 11 cover નહીં થાય. તેથી γ(G) ≥ ceil(11/4)=3.

2. Domination vs Total domination

Total dominating set S: દરેક vertex ઓછામાં ઓછા એક selected vertex સાથે adjacent હોવો જોઈએ. Vertex પોતે Sમાં છે એટલા માટે પોતાને dominate કરતો નથી.

Total domination સામાન્ય રીતે isolated vertex હોય તો શક્ય નથી. કોઈ isolated vertexને neighbor જ નથી.

γₜ(G) = minimum size of a total dominating set

Graphમાં isolated vertices ન હોય તો γ(G) ≤ γₜ(G), કારણ કે total dominating set, ordinary dominating set પણ હોય છે, પણ ordinary dominating set total condition પૂરી ન કરે એ શક્ય છે.

Trick: “Total = everyone needs a teammate.” Selected vertexને પણ બીજો selected neighbor જોઈએ.

Cycle graph quick result

Cycle Cₙમાં domination number સામાન્ય રીતે γ(Cₙ)=⌈n/3⌉. Total domination માટે adjacent selected vertices સહિત coverage check કરવું; formula-based result course/notation મુજબ verify કરીને લખો. Examમાં small cycle હોય તો set explicitly show કરવો સૌથી safe.

3. Matching, maximal અને maximum

Matching M: edgesનો એવો subset જેમાં કોઈ બે edges common endpoint share ન કરે. એક vertex વધુમાં વધુ એક matched edgeમાં આવી શકે.

  • Maximal matching: તેમાં કોઈ extra edge add કરી શકાય નહીં, કારણ કે તે endpoint-sharing કરાવશે.
  • Maximum matching: graphમાં possible matchingsમાંથી સૌથી વધુ edges ધરાવતું matching.
  • Matching number α′(G) / ν(G): maximum matchingમાં edgesની સંખ્યા.
  • Perfect matching: દરેક vertex કોઈ એક matching edgeમાં આવવો જોઈએ.

Mnemonic: Maximal = no more can be added. Maximum = most possible. શબ્દો લગભગ સરખા છે, અર્થ અલગ!

Example: path P₄ = a—b—c—d

M₁={(a,b),(c,d)} એ maximum matching છે, size 2. M₂={(b,c)} maximal છે, કારણ કે બાજુની કોઈ edge add કરી શકાતી નથી; પરંતુ maximum નથી, કારણ કે size માત્ર 1 છે.

Matching number કાઢવાની રીત: disjoint edges પસંદ કરો, maximum શક્ય pair count બતાવો. Maximum સાબિત કરવા માટે upper bound અથવા graphની રચના પ્રમાણે વધુ edges possible નથી તે સમજાવો.

4. Perfect matching અને bipartite graph

Perfect matching: matching જે graphના દરેક vertexને exactly એક વખત match કરે. એટલે graphનો order even હોવો જરૂરી, પણ even order હોવું પૂરતું નથી.

Perfect matching ⇒ |V(G)| is even

Example: 6 verticesમાં 3 disjoint edges બધાં verticesને cover કરે તો perfect matching. 5 vertices હોય તો perfect matching શક્ય નથી. 6 vertices હોવા છતાં graphની edges યોગ્ય ન હોય તો perfect matching ન પણ મળે.

Bipartite graph: vertices બે disjoint sets U અને Wમાં વહેંચાય; દરેક edge Uમાંથી W તરફ જાય, એક જ sideની અંદર edge નહીં હોય. Students–books અથવા interns–tasks assignment એ તેનું real-life model છે.

5. Hall’s Theorem (without proof)

Bipartite graph G=(U,W)માં Uના દરેક vertexને અલગ W-vertex સાથે match કરવું હોય, તો દરેક subset X ⊆ U માટે તેનો neighborhood N(X) ઓછામાં ઓછો X જેટલો હોવો જોઈએ.

Hall condition: |N(X)| ≥ |X| for every X ⊆ U

આ condition true હોય તો Uના બધા verticesને distinct neighbors સાથે match કરી શકાય. જો કોઈ subset X માટે |N(X)| < |X| હોય, તો complete matching impossible.

Example: students and books

3 students {A,B,C}. Preferences: A wants {1,2}; B wants {1,2}; C wants {2}. X={A,B,C} માટે N(X)={1,2}, એટલે |N(X)|=2 < 3. તેથી બધા 3 studentsને અલગ preferred book આપવી impossible.

How to apply in exam

  1. Graphને bipartite sets U,Wમાં લખો.
  2. Relevant subset X of U લો.
  3. તેને જોડાયેલા W vertices N(X) ગણો.
  4. જો કોઈ subset માટે |N(X)| < |X| મળે, તો “No complete matching by Hall’s condition.”
  5. જો બધા subsets condition satisfy કરે, Hall’s theoremથી complete matching exists.
Trick: “Group જેટલો મોટો, options ઓછામાં ઓછા એટલા.” 4 students માત્ર 3 booksની options share કરે તો બધા 4ને unique book આપી શકાતી નથી.
