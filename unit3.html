Two stages: (1) Learning/training phaseમાં classifier બનાવવો; (2) Classification phaseમાં unseen data પર class predict કરવી.

ID3 information gain વાપરે છે; C4.5 gain ratioનો ઉપયોગ કરે છે; CART સામાન્ય રીતે binary split અને Gini index સાથે જોડાય છે. આ algorithms greedy top-down divide-and-conquer રીતે tree બનાવે છે.

Induction algorithm — exam steps

  1. Training records root પર મૂકો.
  2. જો બધા records એક જ classના હોય તો તે classનો leaf બનાવો.
  3. Attributes ન બચે તો majority classનો leaf બનાવો.
  4. Selection measureથી best splitting attribute પસંદ કરો.
  5. દરેક outcome માટે records partition કરીને subtree બનાવો.
  6. કોઈ branchમાં records ન હોય તો parent dataની majority classનો leaf જોડો.

Stopping conditions: બધા samples same class; attributes પૂરા; અથવા partitionમાં samples બાકી ન રહે.

3. Entropy અને Information Gain (ID3)

Entropy datasetની impurity / randomness માપે છે. બધા records એક classના હોય તો entropy 0; classes લગભગ સમાન પ્રમાણમાં હોય તો entropy વધુ.

Entropy(D) = − Σ pᵢ log₂(pᵢ)

Attribute A વડે split કર્યા પછીની weighted entropy:

Info_A(D) = Σ (|Dⱼ| / |D|) × Entropy(Dⱼ)
Gain(A) = Entropy(D) − Info_A(D)

જે attributeનો Information Gain સૌથી વધારે, તેને split માટે પસંદ કરીએ.

PDFના AllElectronics exampleની ગણતરી

કુલ 14 records: buys_computer = Yes 9 અને No 5.

Entropy(D) = −(9/14)log₂(9/14) − (5/14)log₂(5/14)
≈ 0.940 bits

Age પ્રમાણે split:

Age groupYesNoEntropy (approx.)
Youth230.971
Middle-aged400
Senior320.971
Info_age(D) = (5/14)(0.971) + (4/14)(0) + (5/14)(0.971)
≈ 0.694
Gain(age) = 0.940 − 0.694 = 0.246 bits

PDFમાં બીજા gains: income ≈ 0.029, student ≈ 0.151, credit_rating ≈ 0.048 bits. તેથી root તરીકે age પસંદ થાય છે.

Entropy calculator

Trick: Entropy = impurity; Gain = before entropy − after split entropy. Gain ઊંચો એટલે સારો split.

4. Gain Ratio (C4.5)

Information Gain બહુ વધુ outcomes ધરાવતા attribute તરફ biased થઈ શકે છે. ઉદાહરણ તરીકે unique Product_ID પર split કરવાથી દરેક row અલગ થઈ શકે અને information gain બહુ ઊંચો દેખાય, છતાં prediction માટે તે ઉપયોગી નથી.

SplitInfo_A(D) = − Σ (|Dⱼ|/|D|) log₂(|Dⱼ|/|D|)
GainRatio(A) = Gain(A) / SplitInfo_A(D)

SplitInfo attribute કેટલા partitions અને તેમનું size distribution છે તે માપે છે. Gain Ratio gainને આ split informationથી normalize કરે છે.

Trick: Gain Ratio = Information Gain ÷ Split Information. Unique ID જેવા ઘણા outcomesના ખોટા લાભને ઘટાડે છે.

5. Gini Index (CART)

Gini પણ impurity માપે છે. તેમાં દરેક classની probabilityનો square લઈ 1માંથી ઘટાડાય છે.

Gini(D) = 1 − Σ pᵢ²

Binary classesમાં Yes = 9/14 અને No = 5/14:

Gini(D) = 1 − (9/14)² − (5/14)²
= 1 − 81/196 − 25/196
= 90/196 ≈ 0.459

કોઈ split પછી weighted Gini:

Gini_A(D) = Σ (|Dⱼ|/|D|) × Gini(Dⱼ)

સામાન્ય રીતે split માટે weighted Gini જેટલું ઓછું, partition એટલું શુદ્ધ. CART binary splits તપાસે છે; categorical attributeના valuesના subsetsને પણ અલગ રીતે split કરી શકાય.

Trick: Entropy / Gain — ID3; Gain Ratio — C4.5; Gini — CART.

6. K-Nearest Neighbors (KNN)

KNN simple, non-parametric, instance-based algorithm છે. નવા pointના નજીકના K training points શોધે છે. Classificationમાં majority vote; regressionમાં neighborsનું average લઈ શકાય.

  1. K પસંદ કરો.
  2. નવા pointથી દરેક training pointનું distance ગણો.
  3. Distance પ્રમાણે સૌથી નજીકના K neighbors લો.
  4. Classification માટે majority class પસંદ કરો.
Euclidean distance: d(x,z) = √Σ(xⱼ − zⱼ)²

Easy calculation

New point P=(3,3). A=(2,2), B=(4,3), C=(7,7).

d(P,A)=√[(3−2)²+(3−2)²]=√2≈1.414
d(P,B)=√[(3−4)²+(3−3)²]=1
d(P,C)=√[(3−7)²+(3−7)²]=√32≈5.657

K=2 હોય તો નજીકના A અને B છે. તેમની class Blue, Blue હોય તો predicted class Blue.

Kનું મહત્વ: K બહુ નાનું → noise/outlierથી sensitive; K બહુ મોટું → local pattern ધૂંધળું થઈ શકે. Distance-based algorithms માટે features scale કરવી ઘણીવાર જરૂરી છે.

Trick: KNN = નજીકના K મિત્રોનો vote.

7. Support Vector Classification (SVC / SVM)

SVC classes વચ્ચે એવો decision boundary શોધે છે કે નજીકના pointsથી boundaryનું margin શક્ય તેટલું મોટું હોય. Boundaryને નક્કી કરવામાં મદદ કરનારા pointsને support vectors કહે છે.

Diagram માત્ર વિચાર સમજાવે છે; margin/boundaryનું ચોક્કસ plotted geometry નથી.

  • Linear SVC: classes straight boundaryથી અલગ થઈ શકે ત્યારે.
  • Nonlinear SVC: kernel દ્વારા nonlinear boundaries handle કરે.
  • Margin: boundary અને નજીકના support vectors વચ્ચેનું અંતર; મોટું margin સામાન્ય રીતે better generalizationમાં મદદરૂપ.
  • C parameter: classification errors સામે કેટલો penalty; C મોટું હોય તો training errors ઓછા કરવા વધુ ભાર.
Trick: SVM = Support vectors + Maximum margin + Kernel (જ્યારે nonlinear data હોય).

9. Bayesian Classification & Bayes’ Theorem

Bayes’ theorem, evidence મળ્યા પછી hypothesis/classની probability update કરવા વપરાય છે.

P(H|X) = [P(X|H) × P(H)] / P(X)
  • P(H|X): X જોવાયા પછી H સાચું હોવાની posterior probability.
  • P(X|H): H સાચું હોય ત્યારે X મળવાની likelihood.
  • P(H): prior probability.
  • P(X): evidenceની probability.

Easy numeric example

કોઈ રોગ 1% લોકોમાં છે. Test sensitivity 90% છે: રોગ હોય ત્યારે positive. False-positive rate 5% છે. Test positive આવે ત્યારે રોગ હોવાની probability શોધો.

P(D)=0.01; P(+|D)=0.90; P(+|¬D)=0.05
P(+) = 0.90×0.01 + 0.05×0.99 = 0.0585
P(D|+) = (0.90×0.01) / 0.0585 ≈ 0.1538 = 15.38%

Test positive હોવા છતાં posterior માત્ર 15.38% છે, કારણ કે disease rare છે અને false positives વધારે સંખ્યામાં થઈ શકે. આ base-rateનું મહત્વ બતાવે છે.

10. Naive Bayes Classifier

Naive Bayes Bayes’ theorem પર આધારિત classifier છે. “Naive” assumption એ છે કે class આપેલી હોય ત્યારે features conditional રીતે independent છે.

P(C|X) ∝ P(C) × P(X|C)
Naive assumption: P(X|C) = ∏ⱼ P(xⱼ|C)
  1. દરેક classની prior probability P(C) ગણો.
  2. દરેક feature માટે class condition હેઠળ probability ગણો.
  3. દરેક class માટે prior × feature probabilitiesનો product કાઢો.
  4. સૌથી વધારે score ધરાવતી class predict કરો; normalization કરવી હોય તો કુલથી ભાગો.

Play Tennis example: Outlook=Sunny, Humidity=High જેવા features માટે “Yes” અને “No” classની conditional probabilities ગણીને product બનાવાય છે. જે classનો posterior score મોટો, તે prediction.

Zero-frequency સમસ્યા: કોઈ feature/class combination training dataમાં ન આવ્યું હોય તો probability 0 થઈ શકે અને આખો product 0 થઈ જાય. Laplace smoothing (દરેક countમાં નાનું +1 ઉમેરવું) મદદ કરી શકે.
Trick: Naive Bayes = Prior × feature likelihoods; classને શરતે features independent માને છે.

12. Evaluation metrics — formulas અને calculation

Accuracy = (TP + TN) / (TP + TN + FP + FN)
Error rate = 1 − Accuracy
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 × Precision × Recall / (Precision + Recall)

Example: TP=40, TN=50, FP=10, FN=20; total=120.

Accuracy = (40+50)/120 = 75%
Error rate = (10+20)/120 = 25%
Precision = 40/(40+10) = 80%
Recall = 40/(40+20) = 66.67%
F1 ≈ 2×0.8×0.6667/(0.8+0.6667) ≈ 72.73%

Meaning: Precision — positive predict કર્યા તેમાં સાચા કેટલા? Recall — actual positivesમાંથી શોધ્યા કેટલા? F1 — precision અને recallનું harmonic mean.

Interactive metric calculator

Class imbalance: જો 1000 recordsમાં માત્ર 10 cancer cases હોય અને model બધાને “No cancer” કહે, તો accuracy 99% થાય છતાં model એક પણ positive case શોધતું નથી. આવા સમયે Recall, Precision, F1, ROC-AUC અને class-specific metrics જોવાં જરૂરી છે.

13. Fβ, ROC અને AUC

Fβ precision અને recallને weighted harmonic meanથી જોડે છે. β>1 recallને વધુ મહત્વ આપે; β<1 precisionને વધુ મહત્વ આપે. F1માં બંનેનું સમાન વજન છે.

Fβ = (1+β²) × (Precision × Recall) / (β² × Precision + Recall)

ROC curve જુદા classification thresholds માટે True Positive Rate (Recall) સામે False Positive Rate plot કરે છે.

TPR = TP/(TP+FN)
FPR = FP/(FP+TN)

AUC ROC curveની નીચેનો વિસ્તાર છે. સામાન્ય binary settingમાં 1ની નજીક સારું ranking; 0.5 આસપાસ random ranking જેવી કામગીરી. AUC પસંદ કરેલા threshold પરના performanceને એકલું નથી બતાવતું.

Trick: ROC = TPR vs FPR; AUC = curveની નીચેનો area.

14. Model evaluation: Holdout, K-fold અને Bootstrap

Holdout

Dataને એક વાર train/testમાં વહેંચો. ઉદાહરણ: 2/3 train, 1/3 test અથવા 80/20.

લાભ: સરળ અને ઝડપી. મર્યાદા: split બદલાય તો score બદલાઈ શકે.

K-fold Cross-validation

Dataને K foldsમાં વહેંચો. દરેક iterationમાં એક fold validation/test માટે અને બાકીના K−1 training માટે. અંતે K scoresનું average લો.

Example: K=5 હોય તો પાંચ runs; દરેક record એક વાર validation foldમાં આવે.

Bootstrap

Dataમાંથી replacement સાથે random samples બનાવો. એક record ફરી પસંદ થઈ શકે; કેટલાક records sampleમાં ન આવે.

Estimateની variability અથવા ensemble trainingમાં ઉપયોગી.

Fold 1: TestFold 2: TrainFold 3: TrainFold 4: TrainFold 5: Train

આગલા runમાં test fold બદલાય છે; આખરે બધા folds એક-એક વાર validation બને છે.

Trick: Holdout = one split; K-fold = K rotating validation turns; Bootstrap = sampling with replacement.

16. Bagging (Bootstrap Aggregating)

Training dataમાંથી replacement સાથે અનેક bootstrap datasets બનાવાય છે. દરેક dataset પર અલગ model train થાય છે. Classificationમાં majority vote અને regressionમાં averageથી final prediction મળે છે.

  1. Original dataset D લો.
  2. Replacement સાથે K bootstrap samples બનાવો.
  3. દરેક sample પર અલગ base model train કરો.
  4. Modelsના outputs combine કરો.

મુખ્ય હેતુ: Variance ઘટાડવો, ખાસ કરીને unstable models જેમ કે decision treesમાં.

Analogy: ઘણા doctors અલગ-અલગ diagnosis આપે; majority voteથી final decision.

Trick: Bagging = Bootstrap + parallel models + vote/average; variance ઘટાડે.

17. Random Forest

Random Forest baggingનું tree-based version છે. દરેક tree અલગ bootstrap sample પર train થાય છે અને દરેક split વખતે candidate featuresમાંથી random subset જોવામાં આવે છે. આ trees વચ્ચે correlation ઘટાડવામાં મદદ કરે છે.

  • ઘણા decision trees બનાવે છે.
  • Classificationમાં majority vote; regressionમાં average.
  • એક decision tree કરતાં સામાન્ય રીતે વધુ stable.
  • ખૂબ ઊંડા/ઘણા trees અથવા noisy data હોય તો computation વધે; interpretability એક tree કરતાં ઓછી.
Trick: Random Forest = many trees + bootstrap records + random features.

18. Boosting અને Bagging vs Boosting

19. AdaBoost (Adaptive Boosting)

AdaBoost શરૂઆતમાં training examplesને સમાન weights આપે છે. દરેક roundમાં weak classifier train થાય છે; ખોટા classify થયેલા examplesના weights વધે છે અને સાચા examplesના weights ઘટે છે. તેથી આગળનો learner મુશ્કેલ examples પર વધારે ધ્યાન આપે છે.

  1. દરેક training tupleનું initial weight સમાન રાખો.
  2. Weighted data પર classifier train કરો.
  3. તેનો weighted error ગણો.
  4. Classifierની importance/weight તેની error પરથી નક્કી કરો.
  5. ખોટા examplesના weights વધારો; સાચા examplesના ઘટાડો.
  6. Rounds પૂરા થાય ત્યાં સુધી repeat કરો; final prediction weighted voteથી.
Classifier weight (binary AdaBoost): αₜ = ½ ln[(1−errₜ)/errₜ]

અહીં errₜ classifierનો weighted error છે. Error ઓછો હોય તો αₜ મોટો — classifierના voteને વધુ મહત્વ મળે. Error 0.5 કરતાં ખરાબ હોય તો binary AdaBoostમાં learner ઉપયોગી ન રહે.

Trick: AdaBoost = misclassified samplesનું weight ↑; correctly classifiedનું weight ↓; better learnerનું vote weight ↑.

20. Written exam માટે quick revision

  • Classificationના બે stages અને Decision Treeના node/edge/leaf સમજાવો.
  • Entropy, Information Gain, Gain Ratio અને Giniના formulas તથા differences લખો.
  • AllElectronics exampleમાં Entropy(D)=0.940, Info_age(D)=0.694 અને Gain(age)=0.246 સમજાવો.
  • KNN algorithm, Euclidean distance અને Kની અસર solve/સમજાવો.
  • SVCમાં maximum margin, support vectors, C અને kernels સમજાવો.
  • Bayes’ theorem તથા Naive Bayesની conditional independence assumption સમજાવો.
  • Confusion matrixથી Accuracy, Error rate, Precision, Recall અને F1 કાઢો.
  • Holdout, K-fold, Bootstrap તથા ROC/AUCની સરખામણી કરો.
  • Bagging, Random Forest, Boosting અને AdaBoostની કામગીરી અને તફાવત લખો.
