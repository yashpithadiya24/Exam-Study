1. Algorithm શું છે?

Algorithm એટલે input લઈને finite stepsમાં ચોક્કસ output આપતી well-defined પ્રક્રિયા.

મુખ્ય 5 લક્ષણો

  1. Finiteness: મર્યાદિત steps પછી બંધ થાય.
  2. Definiteness: દરેક step સ્પષ્ટ હોય.
  3. Input: zero કે વધુ inputs.
  4. Output: ઓછામાં ઓછું એક output.
  5. Effectiveness: દરેક operation કરી શકાય એવું basic અને finite હોય.

Problem vs Instance

Problem: બે positive integersનું multiplication.

Instance: 981 × 1234.

Instance size n: inputના elements/componentsની સંખ્યા; sortingમાં n = arrayના elements.

2. Algorithm Analysis

Input size n વધે ત્યારે કેટલો સમય (Time Complexity) અને memory (Space Complexity) જોઈએ તે અંદાજવું.

Empirical / Posteriori

Program run કરીને actual time માપવો. Machine, language અને inputથી result બદલાય શકે.

Theoretical / Priori

Codeમાં primitive operations કેટલી વાર ચાલે તે ગણી mathematical function બનાવવી.

Best, Average, Worst case

Caseઅર્થLinear Search example
Bestઓછામાં ઓછા stepsTarget પ્રથમ સ્થાન પર → 1 comparison
Averageસામાન્ય/સરેરાશ inputTarget લગભગ મધ્યમાં → આશરે n/2 comparisons

Linear Search: Best Θ(1), Average Θ(n), Worst Θ(n)

3. Asymptotic Notations

Big O — O(g(n))

Upper bound / growth ઉપરથી મર્યાદિત.

ઉદાહરણ: 3n² + 5n + 7 = O(n²).

Omega — Ω(g(n))

Lower bound.

ઉદાહરણ: 3n² + 5n + 7 = Ω(n²).

Theta — Θ(g(n))

Tight bound: upper અને lower બંને same order.

3n² + 5n + 7 = Θ(n²).

યાદ રાખવાની trick: O = ઉપરની limit, Ω = નીચલી limit, Θ = ચોક્કસ same growth order. Big-O ને હંમેશાં “worst case” કહેવું યોગ્ય નથી; notation bound બતાવે છે, case input પર આધારિત છે.

Growth order — ધીમાથી ઝડપી

1 < log n < n < n log n < n² < n³ < 2ⁿ < n!

Dominant term trick: 7n³ + 2n² + 100 → સૌથી મોટો growth term n³ રાખો → Θ(n³).

Loop complexity ઝડપી ગણો

Calculation example

જો for i=1 to nમાં એક operation થાય અને initialization/check overheadથી કુલ T(n)=2n+3 મળે:

  1. Dominant term = 2n.
  2. Constant multiplier 2 અને constant 3 ignore કરો.
  3. અંતિમ: Θ(n).

5. Sortingની હાથેથી કરાતી calculation tricks

Bubble Sort

Array: 5, 1, 4, 2

  1. Pass 1: (5,1) swap → 1,5,4,2; (5,4) swap → 1,4,5,2; (5,2) swap → 1,4,2,5.
  2. Pass 2: 1,4 same; (4,2) swap → 1,2,4,5.
  3. Pass 3: 1,2 same → sorted.

Comparisons basic version: (n−1)+(n−2)+…+1 = n(n−1)/2. n=4 → 6.

Selection Sort

Array: 29, 10, 14, 37, 13

  1. Minimum 10 → first position: 10,29,14,37,13.
  2. Remaining min 13 → second: 10,13,14,37,29.
  3. Remaining min 14 already placed.
  4. Remaining min 29 → 10,13,14,29,37.

Comparisons = n(n−1)/2 = 5×4/2 = 10, input order બદલાય છતાં basic selectionમાં same comparisons.

Insertion Sort

Array: 7, 3, 5

  1. Key=3; 7 shift right → 3,7,5.
  2. Key=5; 7 shift right, 3 પછી insert → 3,5,7.

દરેક stepમાં left portion sorted છે. Nearly sorted array પર સારું કામ કરે છે.

Counting Sort

Input: 2, 1, 2, 0, 1. Range 0..2.

  1. Frequency: 0→1, 1→2, 2→2.
  2. Frequencyને outputમાં repeat કરો.
  3. Output: 0,1,1,2,2.

સમય Θ(n+k), પરંતુ k બહુ મોટું હોય તો memory ખર્ચ વધે.

Radix Sort

Input: 170, 45, 75, 90, 802, 24, 2, 66.

  1. Ones digit પ્રમાણે stable sort.
  2. Tens digit પ્રમાણે stable sort.
  3. Hundreds digit પ્રમાણે stable sort.

દરેક passમાં digit frequency/bucketsનો ઉપયોગ; stable order જાળવવો જરૂરી.

Heap Sort — Max Heap

Max-heapમાં parent ≥ children. Root maximum હોય છે.

  1. Arrayને max heapમાં બનાવો.
  2. Root અને last element swap કરો.
  3. Heap size એક ઘટાડો, rootને heapify કરો.
  4. બધા elements અંતે sorted થાય.

n elements માટે build-heap Θ(n), repeated removals Θ(n log n).

6. Amortized Analysis

એક operation ક્યારેક મોંઘું હોય, પરંતુ operationsની આખી sequenceનો average cost નાનો હોઈ શકે. Aggregate, Accounting અને Potential ત્રણ methods છે.

Binary counter example

Incrementમાં જમણી બાજુના 1 bits ને 0 કરો અને પહેલી 0 ને 1 કરો.

0 (0000): initial state.

0→1 flip 1 bit; 1→2 flips 2 bits (01→10); 3→4 flips 3 bits (0011→0100). છતાં n incrementsની કુલ bit flips O(n), એટલે amortized cost O(1) પ્રતિ increment.

Aggregate: amortized cost = total cost of n operations ÷ n

7. Exam quick revision + self-check

  • Algorithm characteristics: Finiteness, Definiteness, Input, Output, Effectiveness.
  • O upper bound, Ω lower bound, Θ tight bound.
  • Two nested independent n loops → Θ(n²).
  • Merge/Heap sort → Θ(n log n); basic Bubble/Selection/Insertion worst → Θ(n²).
  • Counting Sort input range k પર પણ આધારિત છે; Radix Sort digit passes પર.
  • Amortized analysis sequenceનું cost જુએ છે, માત્ર એક expensive operationનું નહીં.
