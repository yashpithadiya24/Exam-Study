1. Machine Learning શું છે?

Machine Learning (ML) એ એવી રીત છે જેમાં computer દરેક rule હાથથી લખાવ્યા વગર dataમાંથી patterns શીખે છે અને નવા data માટે prediction અથવા decision કરે છે.

જૂના examples / Data
→
Learning algorithm
→
Model
→
નવા dataની prediction

Example: હજારો spam અને normal emails બતાવવાથી model “free prize”, શંકાસ્પદ links, sender વગેરે patterns શીખે છે. પછી નવી email Spam છે કે નહીં તે અંદાજે છે.

Tom Mitchellની definitionનું સરળ સ્વરૂપ: Experience (E) વધે તેમ task (T) પર performance (P) સુધરે, તો program શીખે છે એવું કહેવાય.
યાદ રાખો: ML = Data + Learning + Prediction. Computerને દરેક નિયમ આપવાના બદલે examples આપીએ છીએ.

2. AI, ML અને Deep Learning (DL)

Artificial Intelligence (AI)
↓ AIની અંદર
Machine Learning (ML)
↓ MLની અંદર
Deep Learning (DL)
  • AI: મશીનને બુદ્ધિશાળી વર્તન કરાવવાની વિશાળ field.
  • ML: data અને statistical methods વડે અનુભવથી સુધરતી AIની રીત.
  • DL: અનેક layers ધરાવતી neural networks દ્વારા complex patterns શીખે છે.

Example: AI = driverless carનું આખું intelligent system; ML = road signs ઓળખવાનું શીખેલું model; DL = imageમાંથી pedestrian ઓળખવા માટે deep neural network.

Trick: AI સૌથી મોટું, ML તેની અંદર, DL સૌથી અંદર.

6. ML Project Lifecycle

→

→

→

→

  1. Problem definition: શું solve કરવું છે અને success કેવી રીતે માપવી તે નક્કી કરો.
  2. Data collection & preparation: data મેળવો; missing values, duplicates અને errors સુધારો; જરૂર પડે તો scale કરો; train/validation/testમાં વહેંચો.
  3. Feature engineering: useful inputs પસંદ કરો, transform કરો અથવા નવા features બનાવો.
  4. Model training: training data પર modelના parameters શીખવો.
  5. Evaluation: unseen/validation data પર યોગ્ય metrics વડે તપાસો; hyperparameters tune કરો.
  6. Deployment & serving: application/APIમાં ઉપયોગ માટે model મૂકો. Batch servingમાં ઘણી predictions એકસાથે; on-demandમાં request આવે ત્યારે.
  7. Monitoring & maintenance: real-world performance, data બદલાવ અને errors જોતા રહો; જરૂર પડે retrain કરો.
Trick: P-D-F-T-E-D-M = Problem, Data, Features, Train, Evaluate, Deploy, Monitor.

7. Learningના ત્રણ મુખ્ય પ્રકાર

Supervised Learning

Labeled data

Input સાથે સાચો answer પણ હોય છે. Model inputથી output mapping શીખે છે.

Example: email → Spam/Not Spam; area → house price.

Tasks: Classification અને Regression.

Unsupervised Learning

Unlabeled data

સાચા labels આપેલા નથી. Model પોતે groups/patterns શોધે છે.

Example: shopping behavior પ્રમાણે customersના groups.

Tasks: Clustering, association rules.

Reinforcement Learning

Reward / penalty

Agent environmentમાં action લે છે અને rewardથી સારો behavior શીખે છે.

Example: game-playing agent જીતે ત્યારે reward.

Key terms: Agent, State, Action, Reward, Environment.

Trick: Supervised = Teacher/answer; Unsupervised = Group શોધે; Reinforcement = Trial + Reward.

Clusteringનો વિચાર

એક clusterની અંદરના points એકબીજાની નજીક (intra-cluster distance ઓછું) અને અલગ clusters વચ્ચેનું અંતર (inter-cluster distance) વધારે રાખવાનો પ્રયાસ થાય છે.

Market Basket: Support અને Confidence

આ concepts PDFમાં market-basket analysis સાથે આવે છે. માનો 100 transactionsમાંથી 30માં Bread અને Milk બંને છે, અને 40માં Bread છે:

Support(Bread → Milk) = 30 / 100 = 30%
Confidence(Bread → Milk) = 30 / 40 = 75%

અર્થ: બધી ખરીદીમાં 30%માં બંને છે; Bread ખરીદનારામાંથી 75% Milk પણ ખરીદે છે.

9. Model-based vs Instance-based; Shallow vs Deep

Model-based

Training dataમાંથી compact model/parameters શીખે છે. પછી modelથી prediction કરે છે.

Example: Linear Regression.

Instance-based

જૂના examples સાચવી રાખે છે; નવા point માટે સમાન examples શોધીને prediction કરે છે.

Example: K-Nearest Neighbors (KNN).

Shallow Learning

સામાન્ય રીતે ઓછા processing layers અથવા manually designed features પર આધાર રાખે છે.

Deep Learning

ઘણી neural-network layers દ્વારા raw dataમાંથી ધીમે ધીમે complex features શીખી શકે છે; સામાન્ય રીતે વધુ data અને computation જોઈએ.

Trick: Model-based = rule/model યાદ રાખે; Instance-based = examples યાદ રાખે.

10. ML applications અને challenges

Applications

  • Image અને speech recognition
  • Recommendation systems
  • Fraud detection
  • Medical diagnosis
  • Self-driving vehicles
  • Spam filtering

Challenges

  • Training data ઓછું હોવું
  • Data quality ખરાબ / labels ખોટાં
  • Irrelevant features — “garbage in, garbage out”
  • અતિ મોટું computation / training cost
  • Model drift: સમય સાથે data બદલાવું
  • Privacy, fairness અને explainability

ઉકેલનો વિચાર: યોગ્ય data એકત્ર કરો, data clean કરો, useful features પસંદ કરો, modelને unseen data પર evaluate કરો અને deployment પછી monitor કરો.

11. Computational Learning Theory — basic overview

PDFના syllabusમાં આ topicનો ઉલ્લેખ છે, પરંતુ lecture slidesમાં તેનો વિગતવાર અલગ section નથી. સમજ માટે નીચેનો basic overview ઉમેર્યો છે.

  • Hypothesis: data પરથી શીખેલો possible rule/function, જે input Xને output Y સાથે જોડે છે.
  • Hypothesis space (H): algorithm પસંદ કરી શકે એવા બધા possible models/rulesનો સમૂહ.
  • Generalization: model માત્ર training examples નહીં, પણ unseen examples પર પણ યોગ્ય prediction કરે તે.
  • Sample complexity: સારી accuracy/generalization મેળવવા કેટલા training examples જરૂરી છે તે અંગેનો વિચાર. Problem મુશ્કેલ હોય અથવા hypothesis space મોટું હોય તો સામાન્ય રીતે વધુ data જરૂરી બની શકે.
  • PAC learning (intuition): Probably Approximately Correct — પૂરતા data સાથે model high probabilityથી acceptable errorની અંદર rule શીખી શકે કે નહીં તે અંગેનું theoretical framework.
Training examples
→
Hypothesis spaceમાંથી model પસંદ
→
Unseen data પર generalization
યાદ રાખો: Learning theory પૂછે છે — “કેટલા examples જોઈએ, કયા પ્રકારના rules શીખી શકાય, અને શીખેલું model નવા data પર કેટલું સારું ચાલશે?”

12. Bias, Variance અને Trade-off

Bias = modelની ખોટી/ખૂબ સરળ ધારણાઓને કારણે થતી systematic ભૂલ. High bias હોય તો model dataનો pattern પકડી શકતું નથી (underfitting).

Variance = training dataમાં નાનો ફેરફાર થાય તો modelની prediction ઘણી બદલાય. High variance હોય તો model training dataને ખૂબ જ યાદ કરે છે (overfitting).
