1. Tree: મૂળ idea

Tree એ એવો simple graph છે જે connected હોય અને તેમાં cycle ન હોય. એટલે કોઈપણ બે vertices વચ્ચે exactly one simple path મળે.

Must-know properties

  • Tree with n vertices has exactly n − 1 edges.
  • Every pair of vertices has exactly one path.
  • Every edge is a bridge: remove any edge and the tree disconnects.
  • Every tree with at least 2 vertices has at least 2 leaves.
  • Adding one extra edge to a tree creates exactly one cycle.
Tree ⇔ connected + acyclic
For a tree: e = n − 1
For a connected graph: rank = n − 1
Memory trick: “Tree = જોડાયેલું, પણ loop વગર.” Vertices n હોય તો edge એક ઓછા: n−1.

Path tree vs Star tree

Path P₅

Chain જેવી રચના. બે leaves; middle vertices degree 2.

Star K₁,₄

એક center બધાં leaves સાથે જોડાયેલો. Maximum degree n−1.

Quick calculation

n = 12 હોય તો edges = 12−1 = 11. n=7, e=6 હોય તો માત્ર edge countથી tree confirm ન કરવો: graph connected પણ હોવો જોઈએ.

Exam answer format: “A tree is a connected acyclic graph. A tree with n vertices has n−1 edges. Conversely, a connected graph with n vertices and n−1 edges is a tree.” પછી values મૂકી calculation બતાવો.

2. Degree sequenceથી tree possible છે કે નહીં?

Undirected graphમાં Degree-Sum Theorem: બધા degreesનો સરવાળો = 2e. Tree માટે e=n−1, એટલે degree sum = 2(n−1).

Σ deg(v) = 2e = 2(n − 1)

ઉદાહરણ: 12 verticesમાં એક degree 5, બે degree 3 અને બાકીના 9 leaves (degree 1) હોય તો sum = 5 + 3+3 + 9×1 = 20. પણ tree માટે 2(12−1)=22 જોઈએ. તેથી આવું tree શક્ય નથી.

Trick: “Degree sum double edges.” પહેલા degree sum ગણો, પછી 2(n−1) સાથે compare કરો.

3. Pendant vertices, distance અને center

Pendant / leaf: degree 1 ધરાવતો vertex. Treeના longest pathના બંને endpoints leaves જ હોય છે, એટલે ઓછામાં ઓછા બે leaves.

  • Distance d(u,v): u થી v સુધીના shortest pathમાં edgesની સંખ્યા. Treeમાં path unique હોવાથી ગણવું સરળ.
  • Eccentricity e(v): v થી સૌથી દૂરના vertex સુધીનું distance.
  • Diameter: બધા pairwise distancesમાં સૌથી મોટું distance.
  • Radius: બધા verticesની eccentricityમાં minimum.
  • Center: minimum eccentricity ધરાવતો vertex/vertices.
e(v) = max d(v,u)
Radius r = min e(v)
Diameter D = max d(u,v)

Path P₅માં e(c)=2; e(b)=e(d)=3; endpointsની eccentricity 4. તેથી center c, radius 2, diameter 4.

Center શોધવાની Leaf-Pruning method

  1. બધા leaves એકસાથે remove કરો.
  2. બાકી treeના નવા leaves પણ remove કરો.
  3. એક vertex બચે તો એક center; બે adjacent vertices બચે તો બે centers.
Memory trick: Center શોધવા બહારના પાંદડા છાંટતા જાઓ, મધ્યનો core બાકી રહેશે.
લખવાની રીત: પહેલા દરેક vertexની eccentricity table બનાવો; પછી minimum = radius અને maximum distance = diameter. Center(s) સ્પષ્ટ લખો.

4. Spanning tree, branch, chord

Connected graph Gનું spanning tree T એ subgraph છે જે Gના બધા vertices રાખે છે, connected રહે છે અને cycle નથી ધરાવતું.

  • n vertices હોય તો દરેક spanning treeમાં n−1 edges.
  • Spanning tree ફક્ત connected graph માટે હોય છે.
  • એક graphના ઘણા spanning trees હોઈ શકે.
  • Branch: spanning treeમાં રહેલી edge.
  • Chord: original graphની એવી edge જે પસંદ કરેલા spanning treeમાં નથી.
Original connected graph→Cycleમાંથી edge કાઢો→બધા vertices + n−1 edges→Spanning tree

Cycle removal algorithm: cycle શોધો, cycleની કોઈ એક edge કાઢો, connectivity જાળવો, cycles ન રહે ત્યાં સુધી repeat કરો.

Rank and nullity (connected graph): rank = n−1; nullity = e−n+1 = e−rank. Nullity એટલે spanning treeની બહાર રહેલી chordsની સંખ્યા.

Branches = n − 1
Chords = e − (n − 1) = e − n + 1
Rank = n − components

ઉદાહરણ: n=8, e=12. Branches = 7; chords = 12−7 = 5; connected graphનો rank 7 અને nullity 5.

Trick: Branch treeમાં, chord cycle વધારતી edge. “Chord count = total edges minus tree edges.”

5. Fundamental circuit અને all spanning trees

એક spanning tree T લો. Tમાં ન હોય તેવી એક chord ઉમેરો તો exactly one unique cycle બને છે. આને તે chordનો fundamental circuit કહે છે.

Fundamental circuitsની સંખ્યા = chordsની સંખ્યા = e − n + 1 (connected G)

ઉદાહરણ: connected graphમાં 8 vertices અને 10 edges હોય, તો chords = 10−8+1 = 3. કોઈપણ spanning treeના સંદર્ભમાં 3 fundamental circuits મળશે.

બધા spanning trees શોધવાનો practical method

  1. Graphની દરેક possible edge selectionમાં n−1 edges લો.
  2. Check કરો કે બધા vertices connected છે.
  3. Cycle ન હોવી જોઈએ.
  4. એકસરખા edge-set ફરી count ન કરો.
Common mistake: “n−1 edges છે એટલે tree” પૂરતું નથી. Connected હોવું જરૂરી છે. Disconnected graph માટે spanning tree નથી.

Cayley’s Theorem: labeled trees

n labeled vertices પર અલગ labeled treesની સંખ્યા:

n^(n−2)

Examples: n=2 → 1; n=3 → 3; n=4 → 4² = 16; n=5 → 5³ = 125. Labels અલગ હોય તો same shape પણ અલગ labeled tree ગણાઈ શકે.

Remember: Cayley = “n power n−2”. આ formula labeled trees માટે છે, unlabeled tree shapes માટે નહીં.

Practice 1: Tree has 15 vertices. Edges?n−1 = 15−1 = 14 edges.
Practice 2: Connected graph has n=9, e=13. Rank, nullity, chords?Rank = n−1 = 8. Nullity = e−n+1 = 13−9+1 = 5. Chords = 5.
Practice 3: Why every tree has at least two leaves?Take a longest path. If an endpoint had another neighbor outside the path, the path could be extended. Therefore both endpoints have degree 1.
Practice 4: Tree with 12 vertices, degrees 5,3,3 and nine leaves possible?Degree sum = 5+3+3+9=20, but required sum = 2(12−1)=22. Impossible.
