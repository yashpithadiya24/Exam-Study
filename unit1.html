2. HTTP, REST અને JSON

REST: resource આધારિત architectural style; resource URLથી ઓળખાય અને standard HTTP methods વડે operate થાય. REST API સામાન્ય રીતે stateless હોય છે.
MethodકામExampleસામાન્ય status
GETવાંચવુંGET /api/products200 OK
POSTનવો record બનાવવોPOST /api/products201 Created
PUTસામાન્ય રીતે resource સંપૂર્ણ updatePUT /api/products/5200/204
DELETEresource કાઢવોDELETE /api/products/5204 No Content

GET vs POST: GET data મેળવવા માટે, સામાન્ય રીતે queryમાં filters; POST server પર resource/operation submit કરવા માટે, data request bodyમાં. GET safe/read-only હોવો જોઈએ; POSTને ફરી મોકલવાથી નવી entry થઈ શકે.

3. Controller, Action અને IActionResult

Controller HTTP requests હેન્ડલ કરે છે; action method ચોક્કસ operation ચલાવે છે. Attribute routingથી URLને action સાથે map કરી શકાય છે.

using Microsoft.AspNetCore.Mvc;

[ApiController]
[Route("api/[controller]")]
public class HelloController : ControllerBase
{
    [HttpGet]
    public ActionResult<string> Get()
        => Ok("Hello API");

    [HttpGet("{id:int}")]
    public IActionResult GetById(int id)
    {
        if (id <= 0) return BadRequest();
        return Ok($"ID = {id}");
    }
}
  • [ApiController]: API-specific behavior, જેમ કે model validationના automatic 400 responses.
  • [Route("api/[controller]")]: controllerના નામ પરથી route base બને.
  • [HttpGet]: GET request સાથે action જોડે.
  • Ok(), NotFound(), BadRequest(): યોગ્ય HTTP response બનાવે.
IActionResultActionResult<T>
વિવિધ પ્રકારના HTTP result આપવા અનુકૂળ.સફળ પરિણામનો type T પણ બતાવે અને error result પણ આપી શકે.

5. Dependency Injection (DI) અને Service Lifetimes

DIમાં class પોતાની dependency જાતે બનાવવાને બદલે framework પાસેથી મેળવે છે. આ loose coupling, testability અને maintenance સુધારે છે.

public interface IStudentService
{
    string GetName();
}
public class StudentService : IStudentService
{
    public string GetName() => "Riya";
}
// Program.cs
builder.Services.AddScoped<IStudentService, StudentService>();
Lifetimeક્યારે નવું instance?ઉપયોગ / યાદ રાખો
Transientદરેક resolution વખતેટૂંકા, lightweight objects.
Scopedએક HTTP request scopeમાં એક instanceWeb requestના data services; સામાન્ય DbContext lifetime.
SingletonApplication lifetimeમાં એક instanceShared stateless service; thread-safety ધ્યાનમાં રાખવી.
મેમરી ટ્રિક: T-S-S = Transient “તુરંત નવું”, Scoped “એક request”, Singleton “એક આખી app”. Singletonમાં scoped service સીધી inject કરવી lifetime issue બનાવે.

સરળ ProductsController (exam-friendly in-memory example)

using Microsoft.AspNetCore.Mvc;
public record Product(int Id, string Name, decimal Price);

[ApiController]
[Route("api/[controller]")]
public class ProductsController : ControllerBase
{
    private static readonly List<Product> items = new()
    {
        new Product(1, "Mouse", 500),
        new Product(2, "Keyboard", 900)
    };

    [HttpGet]
    public ActionResult<IEnumerable<Product>> GetAll() => Ok(items);

    [HttpGet("{id:int}")]
    public ActionResult<Product> Get(int id)
    {
        var p = items.FirstOrDefault(x => x.Id == id);
        return p is null ? NotFound() : Ok(p);
    }

    [HttpPost]
    public ActionResult<Product> Create(Product p)
    {
        var created = p with { Id = items.Count == 0 ? 1 : items.Max(x => x.Id)+1 };
        items.Add(created);
        return CreatedAtAction(nameof(Get), new { id = created.Id }, created);
    }

    [HttpPut("{id:int}")]
    public IActionResult Update(int id, Product input)
    {
        var i = items.FindIndex(x => x.Id == id);
        if (i < 0) return NotFound();
        items[i] = input with { Id = id };
        return NoContent();
    }

    [HttpDelete("{id:int}")]
    public IActionResult Delete(int id)
    {
        var p = items.FirstOrDefault(x => x.Id == id);
        if (p is null) return NotFound();
        items.Remove(p);
        return NoContent();
    }
}

આ demo memoryમાં data રાખે છે; app restart થાય તો data ગુમાય. Database માટે EF Core/Repository ઉપયોગ કરવો.

Exam answer outline: CRUD = Create (POST), Read (GET), Update (PUT/PATCH), Delete (DELETE). Endpoint, input, service/database operation અને યોગ્ય status code સમજાવો.
