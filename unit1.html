1. Computer Network — Basics

વ્યાખ્યા: બે કે તેથી વધુ devices ને wired અથવા wireless રીતે જોડીને data અને resources share કરાવતી વ્યવસ્થા એટલે Computer Network.

ફાયદાFile/printer sharing, internet sharing, ઝડપી communication, flexible access, cost saving, centralized management.
ApplicationsEmail, video conference, banking/business, file-directory services, online games, social networking.

મહત્વની characteristics

Resource sharing, scalability (જરૂર પડે ત્યારે network વધારી શકાય), fault tolerance (એક ભાગ fail થાય તો પણ બાકી ચાલે), security, speed, reliability, interoperability અને centralized management.

યાદ રાખો: Network એટલે devices + connection + data + rules (protocols). Protocol એ communication માટેના નિયમોનો સમૂહ છે.

Network પ્રકાર — વિસ્તાર પ્રમાણે

આ unit માં મુખ્ય સરખામણી LAN, MAN અને WAN ની છે. Bluetooth જેવા ખૂબ નાના personal network ને PAN અને wireless LAN ને WLAN તરીકે પણ ઓળખવામાં આવે છે.

3. Internet, Edge અને Core

Internet: વિશ્વભરના અનેક interconnected networks નો network. Web Internet પર ચાલતી એક service છે—બંને એક જ વસ્તુ નથી.

InternetPublic global network of networks.
IntranetOrganizationની અંદરનું private network; જેમ કે employee HR portal.
Extranetચોક્કસ બહારના partnersને મર્યાદિત access આપતું private network.

Network Edge

End systems/hosts (PC, phone, server) અને edge router નો ભાગ. User applications અહીં ચાલે છે; device network માં entry/exit કરે છે.

Network Core

Routers અને high-speed links નું અંદરનું જાળું, જે packets ને sourceથી destination તરફ forward કરે છે.

Internet switching idea

Network core માં routers packetsને આગળ મોકલે છે. Network edge user-facing systems ધરાવે છે. Routers forwarding table આધારે next hop પસંદ કરે છે.

4. Circuit Switching vs Packet Switching

Circuit SwitchingData શરૂ થાય તે પહેલાં dedicated path/channel establish થાય છે. Connection active હોય ત્યાં સુધી resource reserve રહે છે. Phases: Establish → Transfer → Disconnect. Traditional voice call તેનું ઉદાહરણ છે.
Packet SwitchingMessage ને નાના packets માં વહેંચવામાં આવે છે. Packets shared network links પરથી forward થાય છે; દરેક માટે dedicated circuit reserve નથી. Internetમાં આ મુખ્ય રીત છે.

5. Transmission Media

Sourceથી destination સુધી signal લઈ જતું માધ્યમ. બે મુખ્ય પ્રકાર: Guided (wired) અને Unguided (wireless).

Guided media

Twisted Pair (UTP/STP)બે insulated copper wires spiral રીતે twisted. Twisting crosstalk અને electromagnetic interference ઘટાડે છે. Cheap, lightweight, install કરવું સરળ. UTP સસ્તું પણ noise સામે ઓછું protected; STP shielded, વધારે ખર્ચાળ.
Coaxial CableInner conductor + insulation + braided outer shield + plastic cover. Shielding અને noise immunity સારી. TV અને લાંબી telephone transmission માં ઉપયોગ. Baseband: એક signal; broadband: multiple signals.
Fiber OpticGlass/plastic coreમાં light signal જાય છે; coreની આસપાસ cladding અને બહાર jacket. High bandwidth, long distance, high data rate, low attenuation અને ઓછું weight.
Unguided / WirelessAir/spaceમાં electromagnetic waves. Radio, microwave અને infrared મુખ્ય પ્રકારો.

6. Network Topologies

Devices અને links કેવી રીતે ગોઠવાયેલા છે તેની રચનાને topology કહે છે.

Busબધા devices એક backbone cable સાથે જોડાય. Cheap/simple; પરંતુ backbone fail થાય તો આખું network બંધ અને collisions/troubleshooting સમસ્યા.
Ringદરેક node બે પડોશી node સાથે; loop બને. Collision ઓછા/token access શક્ય; એક node/link fail થાય તો communication તૂટી શકે, node વધારતાં delay વધી શકે.
Starદરેક device central hub/switch સાથે. Setup, expansion અને troubleshooting સરળ; એક edge cable fail થાય તો એક node અસરગ્રસ્ત, પણ central device fail થાય તો મોટો outage.
MeshNodes વચ્ચે અનેક direct paths; fully connected meshમાં દરેક pair વચ્ચે direct link. High reliability/fault tolerance, પણ cable/ports અને management ખર્ચાળ.
TreeRoot અને branches ધરાવતી hierarchy. મોટા networkને ગોઠવવા અને expand કરવા સરળ; backbone/root failure ઘણા devicesને અસર કરે.
Hybridબે કે વધુ topologiesનું combination. Flexible અને scalable, પણ design/management વધુ complex થઈ શકે.
Memory trick: Bus = backbone; Ring = loop; Star = center; Mesh = many paths; Tree = hierarchy; Hybrid = mix.
Common MCQ: Central switch → Star. Maximum fault tolerance/multiple backup paths → Mesh. Backbone cable → Bus. Multiple topologies → Hybrid.

7. Protocol Layers — OSI અને TCP/IP

Layering network communication ને અલગ જવાબદારીઓમાં વહેંચે છે. એક layer નીચેની layerની service વાપરે છે અને ઉપરની layerને service આપે છે.

OSI Model — 7 Layers

7. Application — user network services
6. Presentation — format, encryption, compression
5. Session — session establish/manage/end
4. Transport — end-to-end delivery, ports, reliability
3. Network — logical addressing, routing
2. Data Link — frames, MAC, error detection
1. Physical — bits, signals, media

TCP/IPમાં OSIની Session અને Presentationની ઘણી કામગીરી Application layerમાં આવે છે; Data Link અને Physicalને ઘણીવાર Network Access/Interface તરીકે જોડીને પણ બતાવવામાં આવે છે.

OSI layer functions — exam points

  • Physical: raw bits, electrical/optical/radio signal, connector અને transmission mediumની specifications.
  • Data Link: node-to-node frame delivery, MAC addressing, medium access, error detection.
  • Network: source-to-destination packet delivery, logical address અને route selection; router મુખ્ય device.
  • Transport: process-to-process delivery, segmentation/reassembly, port numbers; TCP reliability/order આપે છે, UDP lightweight છે.
  • Session: applications વચ્ચે session સ્થાપિત, જાળવી અને terminate કરે.
  • Presentation: data format/translation, encryption/decryption અને compression.
  • Application: end-user services જેવા web, email, file transfer.
OSI mnemonic (7→1): “All People Seem To Need Data Processing” = Application, Presentation, Session, Transport, Network, Data Link, Physical. 1→7 યાદ કરવા તેનો reverse order બોલો.

8. Delay, Packet Loss અને Throughput

Delayના ચાર ભાગ

dnodal = dproc + dqueue + dtrans + dprop
Processing delayHeader તપાસવો, bit errors check કરવી, output link પસંદ કરવી.
Queuing delayRouterની queueમાં રાહ જોવાનો સમય; congestionથી વધે.
Transmission delayPacketના બધા bits link પર push કરવા લાગતો સમય.
Propagation delaySignalને linkના એક છેડેથી બીજા છેડે પહોંચવાનો સમય.
Transmission delay = L / R    |    Propagation delay = d / s

અહીં L = packet length (bits), R = link rate (bits/sec), d = physical distance (m), s = propagation speed (m/sec).

Calculation 1 — Transmission delay
Packet = 12,000 bits; link = 1 Mbps = 1,000,000 bits/s.
Delay = 12,000 / 1,000,000 = 0.012 s = 12 ms.
Calculation 2 — PDFનું VoIP example
Packet = 56 bytes = 448 bits; codec rate = 64 kbps. Packet gather time = 448/64,000 = 0.007 s = 7 ms.
Transmission = 448/2,000,000 = 0.000224 s = 0.224 ms; propagation = 10 ms.
Total = 7 + 0.224 + 10 = 17.224 ms (processing/queueingને અહીં ગણ્યા નથી).
Calculation 3 — End-to-end across multiple links
જો દરેક link પર L/R અને d/s આપેલા હોય, દરેક linkનો transmission delay અને propagation delay અલગ કાઢીને ઉમેરો. Store-and-forward packet switchingમાં સામાન્ય રીતે આખો packet મળ્યા પછી આગળ મોકલાય છે, એટલે પ્રશ્નના assumptions ધ્યાનથી વાંચવા.

Packet Loss

એક અથવા વધુ packets destination સુધી ન પહોંચે તે packet loss. Router/switch buffer ભરાય અને traffic intensity વધે ત્યારે loss વધે શકે.

Throughput

દર સેકન્ડે સફળતાપૂર્વક પહોંચેલા dataનો દર; bpsમાં માપાય. End-to-end throughput સામાન્ય રીતે pathની bottleneck capacityથી મર્યાદિત થાય છે.

એક flow માટે throughput ≈ min(link capacities along path)
Calculation 4 — Bottleneck
Path links 10 Mbps, 200 Mbps અને 90 Mbps હોય તો single flow માટે maximum throughput ≤ min(10,200,90) = 10 Mbps.
PDFના shared middle link exampleમાં ચાર flows 200 Mbpsને fair share કરે તો દરેકને 50 Mbps middle-link share મળે; પરંતુ server-side link 10 Mbps હોવાથી દરેક flowની limit min(10,50,90) = 10 Mbps.
ફર્ક યાદ રાખો: Transmission = bits link પર ચડાવવાનો સમય; Propagation = signal મુસાફરીનો સમય; Throughput = સફળ data rate; Delay = સમય.
