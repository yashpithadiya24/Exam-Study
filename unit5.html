1. Algorithms & graph input/output

Algorithm: problem solve કરવા માટે precisely defined, unambiguous stepsનો finite sequence. Algorithm terminate થવો જોઈએ.

Graph computerમાં આ રીતે represent થઈ શકે:

  • Adjacency matrix: vertices વચ્ચે edge છે કે નહીં તે matrixથી.
  • Incidence matrix: rows vertices અને columns edges; entries બતાવે કે vertex edge સાથે incident છે.
  • Edge listing: દરેક edgeને vertex pair તરીકે list કરવી.
  • Two linear arrays: દરેક edge માટે source verticesની array F અને destination verticesની array H.

Output algorithm પર આધારિત હોય છે: shortest-path distance/actual path, subgraphની adjacency matrix, અથવા yes/no result.

Exam point: Input graphની representation questionમાં જે હોય તે જ use કરો; vertex/edge order consistent રાખો.

2. Minimum Spanning Tree (MST)

Weighted graph: દરેક edge સાથે weight/cost/distance જોડાયેલું હોય. Spanning tree: connected graphના બધા verticesને connect કરતો, cycle વગરનો subgraph. n verticesના treeમાં n−1 edges હોય છે.

Minimum spanning tree: connected, undirected, weighted graphનું spanning tree જેમાં total edge weight minimum હોય.

Weight(T) = sum of weights of all edges in T; MST has minimum total weight

Kruskal’s Algorithm (greedy)

  1. બધી edgesને increasing weight મુજબ sort કરો.
  2. સૌથી નાની edge લો.
  3. જો edge add કરતાં cycle બને, તો reject કરો; નહીં તો include કરો.
  4. જ્યાં સુધી n−1 edges પસંદ ન થાય ત્યાં સુધી continue.

સામાન્ય રીતે sparse graphs માટે યોગ્ય. Same weightની edges હોય તો અલગ MST પણ મળી શકે, પણ minimum total weight same રહે.

Prim’s Algorithm (greedy)

  1. કોઈપણ એક vertexથી શરૂઆત કરો.
  2. હાલના treeને કોઈ નવા vertex સાથે જોડતી minimum-weight edge પસંદ કરો.
  3. નવા vertexને treeમાં add કરો.
  4. બધા vertices જોડાઈ જાય ત્યાં સુધી repeat કરો.

Primમાં દર વખતે current treeમાંથી બહારના vertex તરફ જતી minimum edge લો. Cycle બનાવતી edge add ન કરવી. Dense graphs માટે સામાન્ય રીતે અનુકૂળ.

KruskalPrim
Global sorted edge listમાંથી minimum edge.એક vertexથી શરૂ કરીને tree grow કરે.
Cycle બને તો edge reject.Treeને નવા vertex સાથે જોડતી edge પસંદ.
Often sparse graph.Often dense graph.
Trick: Kruskal = sort all edges. Prim = grow from one point.

Mini worked example

Edges: AB=1, BC=2, AC=4, CD=3. Kruskal order: AB(1), BC(2), CD(3), AC(4). First three edges all vertices connect without cycle, so MST={AB,BC,CD}, total weight=1+2+3=6. AC is not needed.

MST answer: sorted edge list / selected edges in order / rejected cycle edges if any / final n−1 edges / total weight.

3. Shortest-path algorithms: overview

Shortest path એ બે vertices વચ્ચે minimum total cost/distance ધરાવતો path છે. “Single-source”માં એક sourceથી બધા verticesની distances; “all-pairs”માં દરેક pairની distance શોધાય.

AlgorithmPurposeNegative edge?Negative cycle
DijkstraSingle-sourceનાઉપયોગ માટે નહીં
Bellman–FordSingle-sourceહાDetect કરી શકે
Floyd–WarshallAll-pairsહાDetect કરી શકે; valid finite shortest path નહીં જો reachable negative cycle હોય

Relaxation: edge u→v weight w માટે જો d[u]+w < d[v], તો d[v]=d[u]+w update કરો.

If d[v] > d[u] + w(u,v), update d[v] = d[u] + w(u,v)

4. Dijkstra’s Algorithm

Greedy single-source shortest-path algorithm. માત્ર non-negative edge weights માટે use કરો.

  1. Source distance 0; બાકીના vertices ∞.
  2. Unvisited verticesમાંથી minimum tentative distance ધરાવતો vertex પસંદ કરો.
  3. તેના દરેક neighbor માટે relaxation કરો.
  4. Current vertexને visited/final mark કરો.
  5. બધા reachable vertices process થાય ત્યાં સુધી repeat.

Mini calculation

Edges S→A=4, S→B=1, B→A=2, A→T=1, B→T=7. Initially d(S)=0, others ∞. S process પછી A=4, B=1. B process પછી A=min(4,1+2)=3 and T=1+7=8. A process પછી T=min(8,3+1)=4. Final shortest route S→B→A→T, cost 1+2+1=4.

Limitation: Negative edge હોય તો Dijkstra fail થઈ શકે, કારણ કે finalized distance પછી negative edge routeને વધુ નાની બનાવી શકે.
Trick: Dijkstra = nearest unvisited vertex; negative weights નહીં.

5. Bellman–Ford Algorithm

Single-source shortest paths માટે; negative edge weights handle કરી શકે છે અને reachable negative-weight cycle detect કરી શકે છે.

  1. Source distance 0, બાકીના ∞.
  2. બધી edges પર relaxation કરો.
  3. આ process V−1 iterations સુધી કરો, જ્યાં V verticesની સંખ્યા છે.
  4. એક extra passમાં કોઈ distance હજી ઘટે તો reachable negative cycle છે.
Repeat edge relaxation V−1 times; extra pass checks negative cycle

કારણ: negative cycle વગર shortest simple pathમાં વધુમાં વધુ V−1 edges હોઈ શકે.

Example relaxation

ધારો d(A)=0 અને edge A→B weight 6 છે; d(B)=∞ હોવાથી update d(B)=6. પછી B→C weight −2 હોય તો d(C)=min(∞,6−2)=4. Negative edge હોવા છતાં relaxation યોગ્ય રીતે કામ કરે છે.

Trick: Bellman–Ford = all edges repeatedly, V−1 rounds, extra round = negative cycle check.

6. Floyd–Warshall Algorithm

Dynamic programming algorithm, all-pairs shortest paths શોધે છે. Positive અને negative edge weights handle કરી શકે, પરંતુ negative cycle હોય તો finite shortest path defined નથી.

Initialization

  • Direct edge weight હોય તો matrix entryમાં એ weight.
  • Direct edge ન હોય તો ∞.
  • Diagonal entries d[i][i]=0.

Update formula

Dᵏ[i,j] = min(Dᵏ⁻¹[i,j], Dᵏ⁻¹[i,k] + Dᵏ⁻¹[k,j])

દરેક k માટે check કરો: iથી j સીધો/અગાઉ જાણીતો path સારો છે કે k મારફતે જતો path સારો છે?

  1. Initial distance matrix D બનાવો.
  2. k=1થી V સુધી each vertexને intermediate તરીકે consider કરો.
  3. દરેક pair (i,j) માટે min(D[i][j], D[i][k]+D[k][j]) update કરો.
  4. Final matrix all-pairs shortest distances આપે છે.

Mini calculation

જો d(A,B)=3, d(B,C)=2 અને હાલ d(A,C)=10 હોય, તો Bને intermediate તરીકે consider કરતાં:

d(A,C) = min(10, 3+2) = 5

એટલે A→B→C routeનો cost 5 છે, જે direct cost 10 કરતાં ઓછો છે. Matrix calculationમાં ∞ સાથે path impossible હોય તો update નહીં થાય.

Trick: Floyd = all pairs; “direct/old route vs through k” compare કરો.

7. Cut-Vertices / Articulation Points & Separability

Cut-vertex (articulation point): connected graphમાંથી vertex અને તેની incident edges remove કરતાં connected componentsની સંખ્યા વધે, તો તે vertex cut-vertex છે. Separable graph: graphમાં cut-vertex હોય તો separable graph કહેવાય (PPT framing).

Simple example

Path A—B—C. B remove કરતાં A અને C disconnected થાય છે, એટલે B cut-vertex. Leaf vertex A remove કરવાથી remaining B—C connected રહે છે, એટલે A cut-vertex નથી.

DFS/Tarjan approach (PPT concept)

  • DFS tree બનાવો.
  • Root condition: DFS rootને બે કે તેથી વધુ DFS-tree children હોય તો root articulation point છે.
  • Non-root condition: કોઈ child vના subtreeમાંથી uના ancestor સુધી back edge ન હોય, તો u articulation point બની શકે.
  • Leaf vertex સામાન્ય રીતે articulation point નથી.

Back edge: DFS-treeના vertexને તેના ancestor સાથે જોડતી non-tree edge. Parent edgeને back edge તરીકે count ન કરવી.

Trick: Cut-vertex = “આ vertex કાઢો અને network તૂટી જાય.” Root: 2+ DFS children; non-root: child subtree ancestor સુધી back edge ન પહોંચે.

8. A Set of Fundamental Circuits (Paton’s Algorithm)

Fundamental circuit એ spanning treeમાં એક non-tree edge (chord) add કરતાં બનતો unique cycle છે. દરેક chord એક fundamental circuit આપે છે.

  1. DFS/BFSથી spanning tree બનાવો.
  2. Non-tree edges/chords identify કરો.
  3. દરેક chordના endpoints વચ્ચે spanning treeમાં પહેલેથી રહેલો unique path શોધો.
  4. આ pathમાં chord ઉમેરો: fundamental circuit મળે.
  5. બધી chords process કરો; બધા fundamental circuitsનો set મળે.
For connected graph, number of fundamental circuits = m − n + 1

અહીં m=edges અને n=vertices. General disconnected graph માટે cycle rank m−n+c, જ્યાં c connected components છે.

Mini example

Triangle A—B—C—Aમાં spanning tree તરીકે AB અને BC પસંદ કરો. Chord AC add કરતાં circuit A—B—C—A મળે. n=3,m=3, તેથી m−n+1=1 fundamental circuit.

Trick: Treeમાં cycle નથી. એક chord add કરો = એક unique fundamental circuit.

Applications: network reliability, cycle basis generation, redundancy analysis.

9. Quick revision & practice

Q1. For a connected graph with 7 vertices, how many edges are in every spanning tree?n−1=7−1=6 edges.
Q2. Kruskal vs Prim?Kruskal edgesને globally increasing weightમાં process કરે અને cycle edge reject કરે. Prim one vertexથી tree grow કરે અને tree-to-new-vertex minimum edge પસંદ કરે.
Q3. Which algorithm is safe for negative edges: Dijkstra or Bellman–Ford?Bellman–Ford. Dijkstra requires non-negative edge weights.
Q4. How many Bellman–Ford passes are required before the extra negative-cycle check?V−1 relaxation rounds, then one extra pass to check whether any distance can still decrease.
Q5. What does Floyd–Warshall calculate?Shortest distances between every pair of vertices.
Q6. Is B a cut-vertex in A—B—C?Yes. Removing B disconnects A and C.
Q7. A connected graph has n=6 vertices and m=8 edges. Number of fundamental circuits?m−n+1=8−6+1=3.
Q8. In Floyd–Warshall, old d(A,C)=10, d(A,B)=3 and d(B,C)=2. New d(A,C)?min(10,3+2)=5.
