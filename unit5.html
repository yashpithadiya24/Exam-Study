1. Artificial Neural Network (ANN) શું છે?

ANN એ human brainના neural networkથી પ્રેરિત computational model છે. ઘણા સરળ processing units (neurons) weights દ્વારા જોડાયેલા હોય છે. Network training examples પરથી weights શીખે છે જેથી prediction error ઘટે.

Input features
→
Hidden layer(s)
weights + activation
→
Output / prediction

Biological neuronમાં dendrites input લે છે, soma/cell body signal process કરે છે અને axon output મોકલે છે. Artificial neuronમાં inputs, weights, summation+bias, activation અને output આ સાથે સરખાવી શકાય.

2. Perceptron અને weighted sum

Single artificial neuron inputsને weightsથી multiply કરે છે, પછી ઉમેરે છે અને bias ઉમેરે છે.

z = Σ(wᵢ xᵢ) + b
Step activation: y = 1 જો z ≥ 0, નહિતર y = 0

Easy example: x₁=1, x₂=0, w₁=0.7, w₂=−0.4, b=−0.2. તો z=(1×0.7)+(0×−0.4)−0.2=0.5. z≥0 એટલે output=1.

Weights connectionની strength બતાવે છે; bias decision boundaryને shift કરવાની flexibility આપે છે. Training દરમિયાન predicted અને true output વચ્ચેનો error જોઈ weights/bias adjust થાય છે.

3. ANN history અને network topologies

Selected history: 1943 McCulloch & Pitts — electrical circuit neuron model; 1949 Donald Hebb — Hebbian learning; 1959 Widrow & Hoff — ADALINE/MADALINE; 1982 Hopfield — bidirectional connections; 1986 Rumelhart અને અન્ય — backpropagation networksને popular બનાવવામાં મોટું યોગદાન.

Single-layer feed-forward

Inputથી output સુધી; hidden layer નથી.

Multilayer Perceptron (MLP)

Input, એક કે વધુ hidden layers અને output layer. Signal આગળ જાય છે; previous layer તરફ cycle થતો નથી.

Input layerમાં સામાન્ય રીતે features જેટલા nodes; output layerમાં task/class પ્રમાણે nodes; hidden layerમાં nodes/layersની સંખ્યા architecture પર આધારિત.

4. ANN કેવી રીતે શીખે છે?

  1. Weights અને biasesને initial (ઘણીવાર random) values આપો.
  2. Training input networkમાં મોકલો — forward propagation.
  3. Prediction અને target વચ્ચે loss/error ગણો.
  4. Error પરથી gradients કાઢો — backpropagation.
  5. Optimizer weights/biases update કરે.
  6. ઘણા epochs સુધી repeat કરો, જ્યાં સુધી error યોગ્ય રીતે ઘટે.
Error / lossનો સરળ વિચાર: E = ½ Σ(target − output)²

Delta rule: weightને error ઘટાડે તે દિશામાં update કરવામાં આવે છે. Learning rate η નક્કી કરે છે કે દરેક update કેટલું મોટું હશે.

wᵢ(new) = wᵢ(old) + η Σ[(t − o) xᵢ] (સરળ delta-rule form)

5. Backpropagation algorithm

Backpropagationમાં પહેલાં forward passથી output કાઢાય છે, પછી output error પાછળની દિશામાં layers મારફતે propagate કરીને દરેક weightનો gradient મળે છે.

Forward propagation

  1. Weights અને biases initialize કરો.
  2. Training sample feed કરો.
  3. દરેક layerમાં weighted sum અને activationથી output કાઢો; loss ગણો.

Backward propagation

  1. Output node માટે error signal કાઢો.
  2. Hidden nodesના error signal પાછળના layerના weighted errors પરથી કાઢો.
  3. Gradients પ્રમાણે weights અને biases update કરો.
  4. Training examples/epochs માટે repeat કરો.
Sigmoid output node માટે: δₖ = Oₖ(1 − Oₖ)(tₖ − Oₖ)
Hidden node માટે: δₕ = Oₕ(1 − Oₕ) Σₖ(Wₕₖ δₖ)

અહીં O = actual activation/output, t = target, W = connecting weight અને δ = error signal. Formula sigmoid activation માટેનું slide-form છે.

ટ્રિક: Forward = prediction બનાવો; Backward = ભૂલનો હિસાબ; Update = weights સુધારો.

7. Hyperparameters

Model parameters (જેમ weights/biases) trainingમાંથી શીખાય છે. Hyperparameters learning process અને architectureને નિયંત્રિત કરે છે; સામાન્ય રીતે training પહેલાં પસંદ કરવામાં આવે છે.

Hyperparameterઅર્થઅસર
Learning rateદરેક updateનું step sizeખૂબ મોટું હોય તો training unstable; ખૂબ નાનું હોય તો ધીમું
Epochsઆખું training dataset modelમાંથી કેટલા વખત પસાર થાયઘણા ઓછા → undertraining; અતિશય trainingથી overfit શક્ય
Batch sizeએક update પહેલાં process કરાતા samplesની સંખ્યાMemory અને gradient noise પર અસર
Layers / nodesNetwork architectureCapacity/complexity નિયંત્રિત કરે
Activationદરેક layerનો output transformNon-linearity અને output range નક્કી કરે

8. TensorFlow, Keras અને MNIST code

Lectureમાં TensorFlow/Keras અને MNIST digit classification example દર્શાવાયું છે. TensorFlow open-source ML framework છે; Keras neural network બનાવવાની high-level API આપે છે. Codeનો મુખ્ય flow: data load → normalize → model define → compile → fit → evaluate/predict.

import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

# MNIST: handwritten digits (0–9)
(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()

# Pixel values 0–255 ને 0–1 rangeમાં લાવો
x_train = x_train / 255.0
x_test = x_test / 255.0

model = keras.Sequential([
    layers.Flatten(input_shape=(28, 28)),
    layers.Dense(128, activation='relu'),
    layers.Dense(10, activation='softmax')
])

model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])
model.fit(x_train, y_train, epochs=5, batch_size=32)
loss, accuracy = model.evaluate(x_test, y_test)
print(accuracy)

Function-by-function: load_data() training/test data આપે છે; Flatten 28×28 imageને 1-D vectorમાં ફેરવે છે; Dense fully connected layer બનાવે છે; compile() optimizer/loss/metrics પસંદ કરે છે; fit() training કરે છે; evaluate() test performance આપે છે. આ example સમજાવટ માટે સરળ reference છે.

9. Deep learning architectures: CNN, RNN, LSTM

CNN — Convolutional Neural Network

Images જેવી grid-structured data માટે ઉપયોગી. Convolution filters local features શોધે છે; pooling feature-mapનું spatial size ઘટાડે છે.

Image
→
Convolution + activation
→
Pooling
→
Dense / class

Max pooling windowમાંથી maximum value રાખે છે; average pooling average રાખે છે.

RNN — Recurrent Neural Network

Sequence/time-series/text માટે. Hidden state અગાઉના inputsમાંથી માહિતી આગળ લઈ જાય છે, જેથી sequence dependencies શીખી શકે.

hₜ = f(xₜ, hₜ₋₁)

LSTM — Long Short-Term Memory

Long-term dependencies શીખવા માટેનું ખાસ RNN. Cell state અને gates માહિતી રાખવી, ભૂલવી કે outputમાં આપવી તે નિયંત્રિત કરે છે.

  • Forget gate: જૂની માહિતીમાંથી શું છોડવું.
  • Input gate: નવી માહિતીમાંથી શું ઉમેરવું.
  • Output gate: હાલની stateમાંથી શું બહાર આપવું.
