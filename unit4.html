1. Network Layer — Forwarding અને Routing

Network Layer sending hostથી receiving host સુધી packets/datagrams પહોંચાડવાનું કામ કરે છે. Sender transport segmentને IP datagramમાં encapsulate કરે છે; router header જોઈને આગળ મોકલે છે.

Forwardingએક router પર આવેલા packetને યોગ્ય output interface પર મોકલવાની local પ્રક્રિયા.
RoutingSourceથી destination સુધી કયો end-to-end path લેવો તે પસંદ કરવાની પ્રક્રિયા.

Routing algorithm forwarding table બનાવવા/અપડેટ કરવામાં મદદ કરે છે. Metrics તરીકે hop count, bandwidth અને delayનો ઉપયોગ થઈ શકે છે.

Memory trick: Routing = route નક્કી કરે; Forwarding = packet આગળ ધપાવે.

3. IPv4 Datagram અને IP Addressing

IPv4 address 32-bitનું હોય છે, સામાન્ય રીતે ચાર decimal octets તરીકે લખાય છે; દરેક octet 0થી 255 સુધી. IPv4 datagram headerમાં version, header length, total length, identification, flags/fragment offset, TTL, upper-layer protocol, header checksum, source/destination IP અને optional fields હોય છે.

IPv4 address = 32 bits = 4 octets × 8 bits

TTL (Time To Live): દરેક router પર ઘટે છે; zero થાય ત્યારે datagram આગળ ન જાય. Fragmentation fields fragments ઓળખવા/reassemble કરવા મદદ કરે છે.

Classful addressing (PDFના syllabus મુજબ)

ClassFirst octet rangeDefault prefixસામાન્ય ઉપયોગ
A0–127 (પ્રથમ bit 0)/8મોટા networks
B128–191/16મધ્યમ networks
C192–223/24નાના networks
D224–239—Multicast
E240–255—Experimental/reserved
Memory trick: A 0–127, B 128–191, C 192–223, D 224–239, E 240–255. Examમાં classful range અને modern CIDRને અલગ રાખો.

4. CIDR અને Subnetting — ગણતરી

CIDR slash notation છે. ઉદાહરણ: /24 એટલે network prefixના 24 bits, એટલે host portion માટે 8 bits બાકી.

Addresses per block = 2^(32 − prefix length)
Traditional usable hosts/subnet = 2^(host bits) − 2

સામાન્ય IPv4 subnetમાં network address અને broadcast addressને host assignment માટે છોડવામાં આવે છે. ખાસ /31, /32 જેવા cases અલગ હોઈ શકે છે.

ઉદાહરણ: /26

  • Host bits = 32 − 26 = 6
  • Total addresses = 2⁶ = 64
  • Traditional usable hosts = 64 − 2 = 62
  • Subnet mask = 255.255.255.192
  • Block size = 256 − 192 = 64; છેલ્લાં octetમાં network starts 0, 64, 128, 192.

Subnetting formula

  • જો host bitsમાંથી s bits subnet માટે borrow કરો: subnets = 2ˢ.
  • જો h host bits બાકી: addresses/subnet = 2ʰ.
  • Valid subnet maskમાં 1 bits સતત ડાબી બાજુ અને 0 bits જમણી બાજુ હોય છે.
ઉદાહરણ: /25 → mask 255.255.255.128; block size 128; દરેક blockમાં 128 addresses અને પરંપરાગત રીતે 126 usable hosts.
Numerical steps: Prefix → host bits → total addresses → usable hosts → mask/block size → network ranges. દરેક step લખો.

5. NAT, ICMP અને IPv6

NAT — Network Address Translation

NAT private/internal addressને public-side address/port સાથે translate કરી શકે છે. તે private networkના અનેક devicesને public IPv4 address share કરાવવામાં મદદરૂપ થાય છે. NAT table mapping નોંધે છે.

Inside local = inside hostનું private address; inside global = outside network પર દેખાતું public-side address. NAT IPv4 address shortage અને internal addressing માટે ઉપયોગી છે.

ICMP

Internet Control Message Protocol network-level error reporting અને diagnostic messages માટે વપરાય છે. ઉદાહરણ: destination unreachable અને time exceeded; pingમાં ICMP echo request/replyનો ઉપયોગ થાય છે.

IPv4 vs IPv6

મુદ્દોIPv4IPv6
Address size32-bit128-bit
લખવાની રીતDotted decimalHexadecimal groups, colon-separated
HeaderVariable length; checksum fieldFixed base header; base header checksum નથી
Address spaceમર્યાદિતખૂબ વિશાળ
યાદ રાખો: IPv4 = 32 bits; IPv6 = 128 bits; ICMP = error/diagnostic; NAT = address translation.

6. Link State અને Distance Vector Routing

Link State (LS) Router network topology/link costsની માહિતી મેળવે છે અને Dijkstra algorithmથી sourceથી બીજા nodes સુધી least-cost paths ગણે છે. સામાન્ય રીતે દરેક router પાસે topologyનું વિસ્તૃત view હોય છે.
Distance Vector (DV) Router પોતાના neighbours સાથે destination સુધીના distance/cost vectors વહેંચે છે. Bellman-Ford આધારિત updateથી routes સુધરે છે; convergenceમાં સમય લાગી શકે.

Dijkstra — high-level steps

  1. Source nodeથી શરૂઆત કરો; source distance 0, અન્ય nodes infinity.
  2. હાલના set બહારનો minimum tentative-distance node પસંદ કરો.
  3. તેના neighboursના distance સુધારો: current cost + link cost.
  4. બધા nodes process થાય ત્યાં સુધી repeat કરો.

LS vs DV

મુદ્દોLink StateDistance Vector
KnowledgeTopology/link-state માહિતીNeighboursના distance vectors
AlgorithmDijkstraBellman-Ford style update
Typical concernComputation અને link-state disseminationCount-to-infinity / convergence

Protocol comparison: RIP distance-vector અને hop-count metric સાથે જોડાય છે; OSPF link-state; BGP inter-domain/path-vector routing માટે વપરાય છે.

Memory trick: LS = map જોઈને route ગણો; DV = neighbours પાસેથી distance શીખો.

7. Hierarchical, Broadcast અને Multicast Routing

Hierarchical routing: મોટા networkને regions/areasમાં વહેંચીને routing table અને routing informationનું કદ નિયંત્રિત કરવામાં મદદ કરે છે.

Broadcast routing: એક senderનો packet બધા hosts અથવા networkના તમામ સંબંધિત nodes સુધી પહોંચાડવાનો પ્રયાસ. Floodingમાં packet અનેક links પર મોકલાય છે; loops/duplicate અટકાવવા control જરૂરી છે.

Multicast routing: એક senderથી ચોક્કસ receiver group સુધી packet પહોંચાડે છે—બધાને નહીં. Router multicast group માટે spanning/tree-like forwarding structureનો ઉપયોગ કરી શકે છે.

Unicastએક sender → એક receiver
Broadcastએક sender → બધા relevant hosts
Multicastએક sender → પસંદ કરેલો group
યાદ રાખો: Uni = one, Broad = all, Multi = group.

8. Network Security — Firewall, VPN, IPsec

Firewall: નક્કી કરેલા security rules પ્રમાણે incoming/outgoing network trafficને allow અથવા block કરે છે. તે policy enforcementમાં મદદ કરે છે; યોગ્ય configuration જરૂરી છે.

VPN (Virtual Private Network): public network ઉપર encrypted/protected tunnel દ્વારા private network access અથવા secure communication આપે છે.

IPsec: IP layer પર packetsને protect કરવા માટેના protocols/architectureનો સમૂહ; authentication, integrity અને encryption જેવી સુરક્ષા સેવાઓ આપી શકે છે, configuration પર આધાર રાખીને.

Termએક વાક્યમાં
FirewallTraffic policy પ્રમાણે filter કરે
VPNPublic network ઉપર protected tunnel
IPsecIP packets માટે security mechanisms

9. Quick Revision + MCQ

  • Network Layer = host-to-host packet delivery.
  • Forwarding = local output interface; Routing = end-to-end path.
  • IPv4 = 32 bits; IPv6 = 128 bits.
  • /26 → 64 total addresses, સામાન્ય રીતે 62 usable hosts.
  • Static = manual; Dynamic = adaptive; Default = fallback.
  • Link State → Dijkstra; Distance Vector → neighbour vectors / Bellman-Ford.
  • RIP → hop count; OSPF → link state; BGP → inter-domain routing.
Q1. Forwarding અને routingમાં ફરક શું?

જવાબ: Forwarding local routerની packet-moving પ્રક્રિયા; routing path selection.

Q2. IPv6 address કેટલા bitsનો?

જવાબ: 128 bits.

Q3. /26માં traditional usable hosts કેટલા?

જવાબ: 62.

Q4. Dijkstra કઈ routing approach સાથે જોડાય છે?

જવાબ: Link State.

Q5. RIP, OSPF, BGPમાંથી link-state protocol કયો?

જવાબ: OSPF.
