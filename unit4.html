1. Matrix representation of a graph

Graphને computerમાં matrix તરીકે represent કરી શકાય. આ PPTમાં મુખ્ય matrices: Adjacency Matrix, Degree Matrix, Laplacian Matrix અને Cut-Set Matrix.

Adjacency Matrix (A)

જો verticesનો order v₁,v₂,…,vₙ હોય, તો A એ n×n matrix છે. Vertex vᵢ અને vⱼ વચ્ચે edge હોય તો Aᵢⱼ=1, ન હોય તો 0.

Aᵢⱼ = 1 if vᵢ adjacent to vⱼ; otherwise 0

Undirected graph માટે A symmetric હોય છે: Aᵢⱼ=Aⱼᵢ. Simple graphમાં diagonal entries 0 હોય છે. દરેક rowનો sum એ corresponding vertexની degree છે.

Worked example

ધારો vertices A,B,C,D અને edges AB, AC, BC, CD છે. Vertex order A,B,C,D રાખો.

A = [0 1 1 0; 1 0 1 0; 1 1 0 1; 0 0 1 0]

Row sums = (2,2,3,1), એટલે degrees deg(A)=2, deg(B)=2, deg(C)=3, deg(D)=1. Matrix બનાવતી વખતે row અને columnનો order એકસરખો રાખવો.

Trick: Adjacency = “કોણ કોની બાજુમાં?” Edge હોય 1, edge ન હોય 0.

2. Degree Matrix (D)

Degree matrix એક diagonal matrix છે. Main diagonal પર verticesની degrees અને બાકીના બધા entries 0.

D = diag(deg(v₁), deg(v₂), …, deg(vₙ))

ઉપરના exampleમાં degrees 2,2,3,1 છે, તેથી:

D = [2 0 0 0; 0 2 0 0; 0 0 3 0; 0 0 0 1]
Trick: Degree matrixમાં diagonal સિવાય બધે zero. Degree list ભૂલશો નહીં.

3. Laplacian Matrix (L)

Laplacian matrix graphની connectivity study કરવા ઉપયોગી છે. તે degree matrixમાંથી adjacency matrix subtract કરીને મળે છે.

L = D − A

એટલે diagonal પર degree, અને જો i≠j હોય તો adjacent vertices માટે −1, non-adjacent માટે 0.

L = [2 −1 −1 0; −1 2 −1 0; −1 −1 3 −1; 0 0 −1 1]

Check: દરેક rowનો sum 0 હોવો જોઈએ. Undirected graph માટે L symmetric છે. Trace(L)=sum of all vertex degrees=2|E|.

Important properties

  • L square n×n matrix છે.
  • દરેક row sum અને column sum 0.
  • Connected graphમાં Laplacianનો zero eigenvalue exactly એક હોય છે.
  • Zero eigenvaluesની સંખ્યા = connected componentsની સંખ્યા.
  • Connected graph માટે second-smallest Laplacian eigenvalue λ₂ positive હોય છે.
Matrix trick: L બનાવો: diagonal = degree, adjacent off-diagonal = −1, બાકીના = 0. પછી row sum zero છે કે નહીં check કરો.

4. Matrix-Tree Theorem (Kirchhoff’s Theorem)

Connected graphમાં spanning treesની સંખ્યા Laplacian matrixના કોઈપણ એક row અને એ જ column દૂર કરીને મળતા cofactorના determinantથી મળે છે.

  1. Graphનું Laplacian matrix L બનાવો.
  2. કોઈપણ એક row અને corresponding column remove કરો.
  3. બાકી રહેલી matrixનું determinant calculate કરો.
Number of spanning trees τ(G) = det(L with one row and matching column deleted)

Mini example: triangle K₃

Triangleમાં દરેક vertexની degree 2 છે:

L = [2 −1 −1; −1 2 −1; −1 −1 2]

ત્રીજી row અને column remove કરતાં minor મળે છે:

M = [2 −1; −1 2] ⇒ det(M)=2×2−(−1)(−1)=3

અેથી triangleમાં 3 spanning trees છે, જે સીધું graph જોઈને પણ verify થાય છે.

Exam format: L matrix → row/column deletion clearly show કરો → determinant steps → final number of spanning trees લખો.

5. Cut-Set Matrix & Fundamental Cut-Set Matrix

Cut-set: edgesનો એવો set જેને remove કરતાં graphના connected components અલગ પડી જાય. Cut-set matrixમાં rows cut-sets અને columns edges દર્શાવે છે. Edge કોઈ cut-setમાં હોય તો entry 1, નહીં તો 0. Oriented graphમાં convention મુજબ +1/−1 પણ વપરાઈ શકે, તેથી questionમાં આપેલી convention અનુસરો.

Fundamental cut-set: એક spanning tree પસંદ કરો. દરેક branchને treeમાંથી remove કરતાં tree બે partsમાં વહેંચાય છે; આ બે parts વચ્ચેના બધા original graph edges એ fundamental cut-set બનાવે છે.

For connected graph: rank of cut-set matrix = rank of fundamental cut-set matrix = n − 1

Connected graphમાં n vertices હોય તો spanning treeમાં n−1 branches હોય છે, એટલે fundamental cut-set rows પણ n−1 થાય છે.

How to construct it

  1. Graph માટે spanning tree પસંદ કરો.
  2. Tree edgesને branches અને non-tree edgesને chords તરીકે label કરો.
  3. એક branch કાઢીને treeના બે components શોધો.
  4. આ બે components વચ્ચેના તમામ graph edges એ cut-setમાં લખો.
  5. દરેક edge માટે 1/0 entriesથી row બનાવો; બધા branches માટે repeat કરો.
Trick: Fundamental circuit માટે chord add કરો; fundamental cut-set માટે branch remove કરો.

Applications

Network link failure analysis, connectivity, electrical networks અને graph partitioningમાં ઉપયોગી. કોઈ cut-setની બધી edges fail થાય તો graph disconnect થાય છે.

6. Eigenvalues and Eigenvectors

Square matrix A માટે non-zero vector x જો Ax=λx satisfy કરે, તો λ eigenvalue અને x corresponding eigenvector કહેવાય.

Ax = λx ⇒ (A − λI)x = 0

Eigenvalues શોધવા માટે characteristic equation solve કરો:

det(A − λI) = 0

Step-by-step method

  1. Matrix A લખો.
  2. A−λI બનાવો, એટલે diagonal entriesમાંથી λ subtract કરો.
  3. det(A−λI)=0 solve કરીને eigenvalues શોધો.
  4. દરેક λ માટે (A−λI)x=0 મૂકો.
  5. Linear equations solve કરીને non-zero eigenvector મેળવો.

Important: Eigenvectorનો કોઈપણ non-zero scalar multiple પણ eigenvector છે. એટલે [1,1] અને [2,2] same directionના valid eigenvectors છે.

Small example

A = [[2,0],[0,3]] માટે characteristic equation (2−λ)(3−λ)=0, એટલે eigenvalues λ=2 અને λ=3. λ=2 માટે eigenvector [1,0]ᵀ; λ=3 માટે [0,1]ᵀ.

Mnemonic: “det=0 gives λ; substitute λ to get x.”

7. Eigenvectors, Fiedler vector & Spectral Clustering

Spectral graph theory graph matricesના eigenvalues/eigenvectors દ્વારા graphની structure સમજવાનો approach છે. Eigenvectors verticesને coordinates આપી શકે છે, clusters ઓળખવામાં મદદ કરે છે અને graph visualization માટે ઉપયોગી છે.

  • Eigenvalues graphની connectivity વિશે માહિતી આપે છે.
  • Laplacianના zero eigenvaluesની સંખ્યા connected components જેટલી છે.
  • Connected graphમાં second-smallest Laplacian eigenvalue λ₂ ને algebraic connectivity કહે છે.
  • λ₂ સાથે સંબંધિત eigenvectorને Fiedler vector કહેવામાં આવે છે; તેનો sign/value verticesને બે groupsમાં વહેંચવામાં મદદ કરી શકે છે.
  • Spectral clustering, community detection, image segmentation અને graph-based machine learningમાં ઉપયોગ થાય છે.

Spectral clustering basic flow:

Graph→Laplacian L→Eigenvalues/vectors→Fiedler vector→Clusters

Clusterમાં internal edges વધારે અને clusters વચ્ચે edges ઓછા હોવા જોઈએ. Cut એટલે બે groups વચ્ચે જતા edgesની સંખ્યા; volume એટલે groupના verticesની degreesનો sum.

Trick: “Eigenvalues = how connected? Eigenvectors = how to split/position?”
Written answer structure: spectral graph theory definition → Laplacian → eigenvalue properties → Fiedler vector → clustering applications.

8. Quick revision & practice

Q1. Find D for degrees 2, 3, 1.D = diag(2,3,1) = [[2,0,0],[0,3,0],[0,0,1]].
Q2. State relation between A, D and L.L = D − A.
Q3. What does each row of A sum to?The degree of the corresponding vertex, for a simple undirected graph.
Q4. How many spanning trees does K₃ have? Use Matrix-Tree Theorem.Delete one row and the same column from its Laplacian. Minor [[2,−1],[−1,2]] has determinant 4−1=3. Therefore 3 spanning trees.
Q5. What does number of zero Laplacian eigenvalues tell us?It equals the number of connected components.
Q6. What is the Fiedler vector used for?It helps identify a useful graph partition and is used in spectral clustering.
Q7. What is the rank of a fundamental cut-set matrix for a connected graph with n vertices?n−1.
