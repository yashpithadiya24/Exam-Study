1. Clustering શું છે?

Clustering એ Unsupervised Learning પદ્ધતિ છે. અહીં training માટે અગાઉથી આપેલા class labels નથી હોતા. Algorithm dataના featuresમાં similarity શોધીને મળતા-જુલતા recordsને એક જ clusterમાં મૂકે છે.

સારો cluster: એક જ clusterની અંદર similarity ઊંચી (high intra-cluster similarity) અને અલગ clusters વચ્ચે similarity ઓછી (low inter-cluster similarity).

ઉપયોગ: customer segmentation, plants/animals grouping, insurance claim groups, city planning, library books અને earthquake risk zones. Clusteringથી outlier પણ શોધી શકાય છે.

યાદ રાખો: અંદરનાં points નજીક, બીજા clusterથી દૂર.

3. K-Means — algorithm અને calculation

K-Means દરેક clusterને તેના centroid (mean point)થી રજૂ કરે છે. શરૂઆતમાં k centers પસંદ થાય છે; દરેક point સૌથી નજીકના centroidને assign થાય છે; પછી દરેક clusterનું નવું mean કાઢાય છે. Assignment બદલાવ બંધ થાય ત્યાં સુધી repeat કરો.

Euclidean distance = √[(x₁ − x₂)² + (y₁ − y₂)²]
New centroid = (બધા x નો mean, બધા y નો mean)
  1. k નક્કી કરો અને k initial centroids પસંદ કરો.
  2. દરેક data pointનું દરેક centroidથી distance ગણો.
  3. સૌથી ઓછા distanceવાળા clusterમાં point મૂકો.
  4. દરેક clusterના pointsનું mean લઈને centroid update કરો.
  5. Cluster assignment સ્થિર થાય ત્યાં સુધી પગલાં 2–4 ફરી કરો.

PDFમાં આપેલું ઉદાહરણ: k=2; initial centers (1,1) અને (5,7). Points (1,1), (1.5,2), (3,4), (5,7), (3.5,5), (4.5,5), (3.5,4.5). પ્રથમ iteration પછી notesમાં centroid આશરે C1=(1.83,2.33), C2=(4.12,5.37) દર્શાવ્યા છે. આગળ ફરી distance કાઢતાં (3,4) બીજા clusterમાં જાય છે.

Initial centroids: dynamically chosen, random, અથવા upper/lower bounds પરથી પસંદ કરી શકાય.

મર્યાદા: k પહેલેથી જોઈએ; initial centersના કારણે પરિણામ બદલાઈ શકે; outliers meanને ખેંચી શકે; spherical/compact clusters માટે વધુ યોગ્ય.
ટ્રિક: K-Means = Assign → Average → Repeat.

4. K-Medoids

K-Medoids પણ partitioning method છે, પરંતુ center તરીકે mean નહીં, datasetનો વાસ્તવિક object medoid લે છે. એટલે K-Means કરતાં outlier સામે સામાન્ય રીતે વધુ robust છે.

  1. k medoids પસંદ કરો.
  2. દરેક pointને નજીકના medoidના clusterમાં assign કરો.
  3. એક medoid અને non-medoid point swap કરીને કુલ dissimilarity/cost જુઓ.
  4. Cost ઘટે તો swap રાખો; નહીં તો પાછું undo કરો.
  5. વધુ cost improvement ન થાય ત્યાં સુધી repeat કરો.

યાદ રાખો: K-Means center ગણિતીય mean હોઈ શકે; K-Medoids center હંમેશાં dataનો actual point છે.

5. Hierarchical clustering અને distance linkage

Agglomerative (AGNES)

દરેક objectથી અલગ cluster શરૂ થાય; નજીકનાં clusters ક્રમશઃ merge થાય; અંતે એક cluster અથવા stopping condition.

Divisive (DIANA)

બધા objects એક clusterમાં શરૂ થાય; પછી clusterને નાના clustersમાં split કરવામાં આવે.

Dendrogram એ tree-like diagram છે જે કયા stage પર કયા clusters merge થયા તે બતાવે છે. Dendrogramને યોગ્ય height પર કાપીને clustersની સંખ્યા પસંદ કરી શકાય છે.

LinkageCluster-to-cluster distance
Single linkબંને clustersના સૌથી નજીકના બે pointsનું distance
Complete linkસૌથી દૂરના બે pointsનું distance
Average linkબંને clustersના તમામ point-pairsના distanceનું average
Centroid linkબંને centroids વચ્ચેનું distance

Weakness: Agglomerative merge થયા પછી સામાન્ય રીતે પાછું undo કરી શકાતું નથી; મોટા data માટે ખર્ચાળ થઈ શકે.

6. BIRCH અને CHAMELEON

BIRCH (Balanced Iterative Reducing and Clustering using Hierarchies) મોટા datasets માટે incremental hierarchical clustering પદ્ધતિ છે. તે dataને compact Clustering Feature (CF)થી summarize કરે છે.

CF = (N, LS, SS)
N = pointsની સંખ્યા · LS = pointsના vectorsનો linear sum · SS = squared valuesનો sum

CF tree height-balanced tree છે; leaf entries નાના subclustersનું summary રાખે છે. તેથી બધાં raw pointsને વારંવાર process કરવાની જરૂર ઘટે છે.

CHAMELEON: graph-based hierarchical method. k-nearest-neighbor graph બનાવે છે અને clusters વચ્ચેની relative interconnectivity તથા relative closenessનો ઉપયોગ કરીને clusters merge કરે છે. Local structureને ધ્યાનમાં લેવું એ તેનો મુખ્ય વિચાર છે.

7. Density-based clustering: DBSCAN

DBSCAN dense regionsને clusters તરીકે શોધે છે. Parameters: Eps = neighborhood radius અને MinPts = Eps neighborhoodમાં core બનવા માટે જરૂરી ઓછામાં ઓછા points.

Point typeઅર્થ
Core pointEps-neighborhoodમાં ઓછામાં ઓછા MinPts points
Border pointCore pointના neighborhoodમાં હોય પણ પોતે core માટે પૂરતા neighbors ન હોય
Noiseકોઈ clusterમાં જોડાતો નથી

Algorithm outline: બધા points unvisited કરો → એક unvisited point પસંદ કરો → Eps-neighbors શોધો → neighbors ≥ MinPts હોય તો cluster expand કરો → density-reachable points ઉમેરો → નહીં તો noise તરીકે mark કરો (પછી clusterમાં જોડાય તો label update થઈ શકે).

ટ્રિક: DBSCAN = radius (Eps) + minimum neighbors (MinPts) + noise handling.

ફાયદા: k આપવાની જરૂર નથી, arbitrary-shaped clusters શોધે, noise ઓળખે. મર્યાદા: density જુદી હોય તેવા clusters અને યોગ્ય Eps/MinPts પસંદ કરવું મુશ્કેલ હોઈ શકે.

8. Outlier detection

Outlier એવો record છે જે સામાન્ય patternથી નોંધપાત્ર રીતે અલગ હોય. ઉદાહરણ: સામાન્ય card spendingથી ખૂબ મોટો transaction, sensorની અસામાન્ય reading.

  • Global outlier: આખા datasetની તુલનામાં અસામાન્ય.
  • Contextual outlier: ખાસ contextમાં અસામાન્ય, જેમ કે શિયાળામાં કોઈ શહેરનું અસામાન્ય ઊંચું તાપમાન.
  • Collective outlier: recordsનો એક group સાથે મળીને અસામાન્ય pattern બનાવે.

મુશ્કેલીઓ: સામાન્ય behaviorની સંપૂર્ણ વ્યાખ્યા કરવી મુશ્કેલ; outlierના બધા પ્રકાર trainingમાં ન દેખાય; noise અને સાચા outlier વચ્ચે ફરક કરવો પડે.

Methods: supervised (labeled normal/outlier examples), unsupervised (labels વગર), proximity-based (neighbors દૂર), clustering-based (નાના/વિખરાયેલા clustersમાં points outlier હોઈ શકે).

9. Feature selection અને feature extraction

Feature selection = મૂળ featuresમાંથી relevant features પસંદ કરીને irrelevant/redundant features કાઢવા. Feature extraction = મૂળ featuresને transform કરીને ઓછા સંખ્યાના નવા features બનાવવાં. Feature engineering = ઉપયોગી features બનાવવાની/રૂપાંતરિત કરવાની પ્રક્રિયા.

Methodવિચારઉદાહરણ
FilterModel train કર્યા વગર feature relevance માપેInformation Gain, Chi-square
WrapperFeature subsets સાથે model train/evaluate કરેForward selection, backward elimination, RFE
EmbeddedTraining દરમિયાન feature selection/importanceModelના training processમાં પસંદગી

Forward selection: ખાલી setથી શરૂ કરીને એક-એક useful feature ઉમેરો. Backward elimination: બધા featuresથી શરૂ કરીને ઓછા ઉપયોગી feature કાઢો. RFE: model-based ranking પ્રમાણે features દૂર કરતાં જાઓ.

Chi-square test: categorical features અને target વચ્ચે association છે કે નહીં તપાસે. H₀: બંને variables independent છે; H₁: association છે. Expected frequency = (row total × column total) / grand total. પછી χ² = Σ (Observed − Expected)² / Expected. Critical value/p-value સાથે નિર્ણય લેવાય.

10. Curse of dimensionality

Featuresની સંખ્યા વધે તેમ feature-spaceનું volume ઝડપથી વધે છે; સમાન data માટે points sparse બની જાય છે. Distanceની usefulness ઘટી શકે, computation વધે અને overfittingનો જોખમ વધે. Feature selection અથવા dimensionality reductionથી આ સમસ્યા ઓછી કરી શકાય.

11. PCA — Principal Component Analysis

PCA unsupervised dimensionality-reduction / feature-extraction technique છે. તે dataની સૌથી વધુ variance પકડતી નવી orthogonal directions (principal components) શોધે છે.

  1. દરેક feature standardize/mean-center કરો.
  2. Covariance matrix ગણો.
  3. Eigenvalues અને eigenvectors શોધો.
  4. Eigenvalues મોટા હોય તે પ્રમાણે components sort કરો.
  5. જરૂરી top components પસંદ કરીને original data project કરો.
Cov(X,Y) = Σ[(xᵢ − x̄)(yᵢ − ȳ)] / (n − 1)
Eigen equation: C v = λ v

મોટું eigenvalue એટલે તે eigenvectorની દિશામાં વધુ variance. PCAમાં labelsનો ઉપયોગ જરૂરી નથી; તેથી તે unsupervised છે.

યાદ રાખો: Standardize → Covariance → Eigen → Sort → Project.

PCA slidesમાં numerical example છે; અહીં તેની આખી eigenvalue ગણતરી ફરીથી ટાઇપ કરવાને બદલે examમાં લખવાના steps અને અર્થ આપ્યા છે.

12. LDA — Linear Discriminant Analysis

LDA supervised dimensionality reduction છે: classesને શક્ય તેટલી સારી રીતે અલગ પાડે તેવી projection શોધે છે. PCA કુલ variance પર ધ્યાન આપે છે; LDA class separation પર ધ્યાન આપે છે.

  1. દરેક classનું mean vector શોધો.
  2. Within-class scatter matrix (Sᵥ / Sᵥᵢ તરીકે પણ લખાય) ગણો.
  3. Classes વચ્ચેનો ફરક માપો અને projection vector મેળવો.
  4. Dataને આ vector પર project કરો.
Two-class projection direction: w = Sᵥ⁻¹ (μ₁ − μ₂)

અહીં μ₁, μ₂ class means અને Sᵥ within-class scatter matrix છે. Examમાં ખાસ લખો: LDA supervised છે; PCA unsupervised છે.
