1. Dynamic Programming (DP)

DP optimization problemsમાં subproblemsના answers એક વાર ગણાવી tableમાં store કરે છે, જેથી ફરી એ જ calculation ન કરવી પડે. Overlapping subproblems અને optimal substructure હોય ત્યારે ખાસ ઉપયોગી છે.

Top-down

Recursion + memoization: જરૂર પડે ત્યારે solve કરો અને result cache કરો.

Bottom-up

નાના base casesથી table ભરીને મોટા answer સુધી પહોંચો.

  1. Optimal solutionની structure ઓળખો.
  2. Optimal value માટે recurrence બનાવો.
  3. Bottom-up રીતે values compute કરો.
  4. Tableમાંથી actual solution પાછો reconstruct કરો.
Principle of optimality: optimal decision sequenceમાં યોગ્ય subproblem માટેનો બાકીનો ભાગ પણ optimal હોવો જોઈએ.

2. Binomial Coefficient

C(n,k) = nમાંથી k વસ્તુઓ પસંદ કરવાની રીતો. Base cases C(n,0)=C(n,n)=1. Recurrence: C(n,k)=C(n−1,k−1)+C(n−1,k).

C(4,2)=C(3,1)+C(3,2)=3+3=6

Pascal triangleની દરેક અંદરની value ઉપરની બે valuesના સરવાળા જેટલી હોય છે. DPથી દરેક C(n,k) tableમાં એક વાર ભરી શકાય.

3. Make Change — DP

Coin denominations માટે dp[x] = amount x બનાવવા જરૂરી minimum coins. dp[0]=0 અને દરેક coin c માટે dp[x]=min(dp[x],1+dp[x−c]) જ્યારે x≥c.

આ interactive exampleમાં coins {1,5,6,8} છે, જે Unit 4 PDFમાં દેખાતી denomination example સાથે સુસંગત છે.

4. 0/1 Knapsack — Dynamic Programming

દરેક itemને આખો લેવો કે ન લેવો; break કરી શકાતો નથી. Let dp[i][w] = પ્રથમ i itemsથી capacity wમાં maximum profit.

જો wᵢ > w: dp[i][w]=dp[i−1][w]
નહીં તો: max(dp[i−1][w], vᵢ + dp[i−1][w−wᵢ])

Interactive example

Items: (weight, value) = (1,1), (2,6), (5,18), (6,22), (7,28); capacity 11.

Greedy by highest value/weight can fail for 0/1 knapsack. PDF example: weight 50/value 3000 અને weight 60/value 4200 સાથે capacity 110માં total profit 7200, જે single weight-100/value-7100 item કરતાં વધુ છે.

5. All-Pairs Shortest Path — Floyd’s Algorithm

Floyd algorithm દરેક vertexથી દરેક vertex સુધી shortest distance શોધે છે. Intermediate vertex kનો ઉપયોગ કરીને D[i][j] update થાય છે.

Dᵏ[i][j] = min(Dᵏ⁻¹[i][j], Dᵏ⁻¹[i][k] + Dᵏ⁻¹[k][j])
  1. Initial matrixમાં direct edge weight; edge ન હોય તો ∞; diagonal 0.
  2. દરેક k માટે દરેક i,j pair પર ઉપરનું formula લાગુ કરો.
  3. અંતિમ matrixમાં all-pairs shortest distances મળે.

Complexity: Time O(V³), space O(V²).

Floyd update demo

Initial distances: A→B=4, A→C=11, B→C=2. Bને intermediate ગણીએ તો A→C = min(11,4+2)=6.

Before: A→C = 11   →   After via B: 4 + 2 = 6

Negative edge weights હોઈ શકે, પરંતુ negative cycle હોય તો shortest-path distances well-defined નથી.

6. Matrix Chain Multiplication

Matrix multiplication associative છે: (AB)C = A(BC), પણ scalar multiplicationની સંખ્યા parenthesization પ્રમાણે બદલાય છે. DP ઓછામાં ઓછા scalar multiplicationsવાળી order શોધે છે.

m[i,j] = min₍ᵢ≤k<ⱼ₎ {m[i,k] + m[k+1,j] + pᵢ₋₁ pₖ pⱼ}

Worked example

A₁: 10×30, A₂: 30×5, A₃: 5×60.

  • (A₁A₂)A₃: 10×30×5 + 10×5×60 = 1500 + 3000 = 4500.
  • A₁(A₂A₃): 30×5×60 + 10×30×60 = 9000 + 18000 = 27000.

અટલે optimal order (A₁A₂)A₃ છે.

Complexity: Standard DP time O(n³), space O(n²).

7. Assembly Line Scheduling

બે assembly lines પર stationsની processing time અને line બદલવાની transfer time હોય છે. DP દરેક station સુધી પહોંચવાનો minimum time રાખે છે.

f₁[j] = min(f₁[j−1]+a₁[j], f₂[j−1]+t₂[j−1]+a₁[j])
f₂[j] = min(f₂[j−1]+a₂[j], f₁[j−1]+t₁[j−1]+a₂[j])

અહીં a₁[j], a₂[j] = station processing times; t₁/t₂ = બીજી lineમાંથી transfer cost. છેલ્લે exit times ઉમેરો અને નાનું total પસંદ કરો.

યાદ રાખવાની રીત: “same line” સામે “switch line + transfer” — બંનેની min લો.

8. Longest Common Subsequence (LCS)

બે stringsમાં character order જાળવીને મળતી સૌથી લાંબી common subsequence. Characters contiguous હોવા જરૂરી નથી.

જો Xᵢ=Yⱼ: L[i,j]=1+L[i−1,j−1]
નહીં તો: L[i,j]=max(L[i−1,j], L[i,j−1])

Interactive LCS table

Strings: ABCBDAB અને BDCABA.

Complexity: Time O(mn), space O(mn) for standard table.

Subsequenceમાં વચ્ચેના characters skip કરી શકાય. Substringમાં characters સતત (contiguous) હોવા જરૂરી છે.

9. Quick Revision + MCQs

  • DP repeated subproblem results store કરે છે.
  • 0/1 Knapsack: item whole or not; DP state item count અને capacity પર આધારિત.
  • Floyd: all-pairs shortest path, O(V³).
  • Matrix chain: matrix order નહીં બદલો, માત્ર parenthesization બદલો.
  • LCS recurrenceમાં match → diagonal + 1; mismatch → top/left maximum.
