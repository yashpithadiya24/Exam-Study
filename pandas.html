1. Pandas શું છે? Series vs DataFrame

Pandas Python library છે જે tabular/labeled data વાંચવા, ગોઠવવા, filter કરવા, clean કરવા અને analyze કરવા ઉપયોગી છે. Import convention: import pandas as pd.

StructureDimensionસરળ અર્થ
Series1-DLabelled index ધરાવતી એક column જેવી structure
DataFrame2-DRows અને columns ધરાવતું table; અલગ columnsમાં અલગ data types હોઈ શકે
import pandas as pd

s = pd.Series([10, 20, 30])
print(s)
print(s[0])  # 10

df = pd.DataFrame({
    "Name": ["Asha", "Jay", "Mira"],
    "Marks": [78, 64, 91]
})
print(df)

2. Series બનાવવી, index અને time series

pd.Series(data, index=..., dtype=...) Series બનાવે છે. Index ન આપો તો default 0થી શરૂ થાય છે. dtype data type નક્કી કરે છે; index custom labels આપે છે.

s = pd.Series([50, 60, 70], index=["Math", "ML", "CN"])
print(s["ML"])  # 60

dates = pd.to_datetime("2026-01-01") + pd.to_timedelta(range(3), unit="D")
daily = pd.Series([12, 15, 11], index=dates)
print(daily)

pd.to_datetime() date/timeમાં ફેરવે છે; pd.to_timedelta(..., unit="D") દિવસોના offsets બનાવે છે. Time seriesમાં datetime index સામે readings રાખી શકાય.

3. DataFrame બનાવવું અને data access

pd.DataFrame(data, index=..., columns=...) table બનાવે છે. Columns પસંદ કરવા df["Marks"]; multiple columns માટે df[["Name","Marks"]].

df = pd.DataFrame(
    {"Name": ["Asha", "Jay", "Mira"],
     "Marks": [78, 64, 91]},
    index=[101, 102, 103]
)

print(df["Marks"])                  # one column
print(df[["Name", "Marks"]])        # two columns
print(df.loc[101])                  # row by label
print(df.iloc[0])                   # row by position
print(df.loc[101, "Marks"])         # single value: 78
print(df.iloc[0, 1])                # same value

loc vs iloc: loc labelથી access કરે છે; iloc zero-based integer positionથી. આ સૌથી મહત્વનો exam difference છે.

4. Row/column ઉમેરવું અને delete કરવું

નવી column assign કરીને બનાવી શકાય. drop() row/column દૂર કરે છે; axis=0 rows અને axis=1 columns માટે. inplace=True original DataFrameમાં ફેરફાર કરે છે.

df["Bonus"] = df["Marks"] + 5
df = df.drop(index=102)              # remove row label 102
df = df.drop(columns=["Bonus"])      # remove column

# subset: selected rows and columns
subset = df.loc[[101, 103], ["Name", "Marks"]]
# all columns except one
without_name = df.loc[:, df.columns != "Name"]

Examમાં code materialમાં દેખાતી જૂની syntax કરતાં label/column-based સ્પષ્ટ syntax સમજવી: drop(index=...) row માટે, drop(columns=...) column માટે.

5. Conditional selection

Condition આપતાં Boolean Series/DataFrame મળે છે. તેને df[condition]માં આપવાથી matching rows મળે છે. Multiple conditions માટે દરેક conditionને parenthesesમાં રાખો અને & (AND), | (OR) વાપરો.

df = pd.DataFrame({
    "Name": ["Asha", "Jay", "Mira"],
    "Marks": [78, 64, 91]
})
print(df[df["Marks"] > 70])
print(df[(df["Marks"] >= 70) & (df["Marks"] < 90)])

6. Index set/reset અને MultiIndex

df.set_index("Column") પસંદ કરેલી columnને row index બનાવે છે. reset_index() indexને ફરી સામાન્ય columnમાં લાવી default integer index આપે છે. MultiIndexમાં rowને એક કરતાં વધુ labelsથી ઓળખી શકાય, જેમ કે College અને Year.

df = pd.DataFrame({
    "College": ["A", "A", "B"],
    "Year": [2024, 2025, 2024],
    "CPI": [8.1, 8.4, 7.9]
})
multi = df.set_index(["College", "Year"])
print(multi.loc[("A", 2025)])
print(multi.reset_index())

CSVમાંથી MultiIndex સીધો બનાવવો હોય તો pd.read_csv("file.csv", index_col=[0,1]) જેવી syntax વાપરી શકાય.

7. Cross-section: xs()

xs() (cross-section) MultiIndex DataFrameમાંથી કોઈ index levelનો section પસંદ કરે છે.

# multiindex has levels: College and Year
print(multi.xs("A", level="College"))

અર્થ: College levelમાં label "A" ધરાવતા rows મેળવો; levelનું નામ/position data પ્રમાણે આપો.

8. Missing data: isna, dropna, fillna, interpolate

Missing value Pandasમાં સામાન્ય રીતે NaN તરીકે દેખાય છે. પહેલા isna()/isnull()થી શોધી શકાય; પછી જરૂર મુજબ drop અથવા fill કરવું.

Functionકામમહત્વનું parameter
isna()Missing positions માટે True—
dropna()Missing ધરાવતી rows/columns દૂરaxis, how, subset
fillna(value)Missing value replaceconstant, dictionary અથવા statistic
interpolate()આસપાસના values પરથી અંદાજે fillmethod/data type પ્રમાણે
import numpy as np
df = pd.DataFrame({
    "A": [1.0, np.nan, 3.0],
    "B": [10.0, 20.0, np.nan]
})

print(df.isna())
print(df.dropna())                 # any missing row removed
print(df.fillna(0))                # missing -> 0
print(df["A"].fillna(df["A"].mean()))
print(df.interpolate())            # interpolate along index

કઈ પદ્ધતિ પસંદ કરવી? Dropna data ઘટાડે છે; fillna constant/statistic મૂકે છે; interpolate values વચ્ચે trend હોય ત્યારે ઉપયોગી. Examમાં missing dataનો context અને પસંદ કરેલી રીતનો કારણ લખો.

9. GroupBy — split, apply, combine

groupby() સમાન categoryના rowsને groupsમાં વહેંચે છે. સામાન્ય workflow: split → apply calculation → combine results. તે groupsને list કરવી, multiple columnsથી group કરવી, aggregate અને describe કરવા ઉપયોગી છે.

df = pd.DataFrame({
    "College": ["A", "A", "B", "B"],
    "Enno": [1, 2, 3, 4],
    "CPI": [8.0, 9.0, 7.0, 8.0]
})
print(df.groupby("College")["CPI"].mean())
print(df.groupby("College").agg({"CPI": ["mean", "max"]}))
print(df.groupby("College").describe())

groupby("College") groups બનાવે છે; mean() average આપે છે; agg() એકથી વધુ aggregate functions ચલાવે છે; describe() count, mean, std, quartiles જેવી summary આપે છે.

10. Concatenate, Join અને Merge

Operationમુખ્ય વિચારક્યારે?
pd.concat()DataFramesને rows/columnsની દિશામાં જોડેસમાન પ્રકારનાં tables stack કરવા
df.join()મોટાભાગે index આધારિત joinએક DataFrameમાં બીજા DataFrameની columns ઉમેરવા
pd.merge()Database-style join, columns/keyથી matchCommon key જેમ RollNo પરથી tables જોડવા
# Stack rows
all_students = pd.concat([df1, df2], axis=0, ignore_index=True)

# Join using index
joined = left.join(right)

# Merge using a common column
merged = pd.merge(students, marks, on="RollNo", how="inner")

axis=0 સામાન્ય રીતે rows નીચે જોડે છે; axis=1 columns બાજુમાં જોડે છે. Mergeમાં how inner/left/right/outer પસંદ કરી શકાય છે.

11. CSV અને Excel files વાંચવી

read_csv() CSV fileને DataFrameમાં વાંચે છે. read_excel() Excel spreadsheet વાંચે છે. File path, separator, selected columns, header અને index જેવા parameters ઉપયોગી છે.

import pandas as pd

df_csv = pd.read_csv("students.csv")
df_selected = pd.read_csv("students.csv", usecols=["RollNo", "Name"])
df_index = pd.read_csv("marks.csv", index_col="RollNo")

df_excel = pd.read_excel("students.xlsx", sheet_name=0)
print(df_csv.head())

head() શરૂઆતની rows બતાવે છે; usecols પસંદ કરેલી columns વાંચે છે; sheet_name Excelની sheet પસંદ કરે છે; index_col columnને index બનાવે છે. Excel support માટે environmentમાં યોગ્ય engine (જેમ openpyxl) જરૂરી હોઈ શકે.
